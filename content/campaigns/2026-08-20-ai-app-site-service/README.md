# AIアプリサイト サービス発信パック

AI相談を「AIを学ぶ場所」だけでなく、相談した業務課題を小さな仕組みへ変えるサービスとして伝えるための再利用パックです。

## 使う順番

1. [service-offer.md](service-offer.md) でサービスの説明、対象、価格、無料相談の進め方を確認する。
2. [ad-copy.md](ad-copy.md) からFacebook・Instagram・リール用の文言を選び、画像または画面録画を合わせる。
3. リンク先は `/ai-app-site/` を基本にし、広告の目的が予約・見積もりなら用途別ページを使う。
4. 実投稿・広告出稿の前に、対象アカウント、予算、公開リンク、画像の権利、数値表現を確認する。

## 公開導線

- 中核ページ: `/ai-app-site/`
- 用途別: `/ai-estimate/`、`/ai-inquiry/`、`/ai-reservation/`、`/ai-shift/`、`/ai-blog/`
- 無料相談準備: `/lectures/2026-08-ai-app-site-consult-sheet.html`
- 行動: 初回無料相談の予約

## 表現ルール

- 「AIサイトを作ります」ではなく、減らせる手作業と増やせる時間を伝える。
- 青い脳、ロボット、回路の定番画像は使わない。PCやスマホ画面、入力・通知・PDFなど仕事が進む様子を見せる。
- 実績数値は、公開許可と根拠があるものだけを掲載する。ここにある時間削減の文言は広告の仮説であり、成果保証ではない。
- 実投稿、広告出稿、DM送信はこのパックに含まれない。
