# CEO 専属タスクロードマップ — クライミングコンサル案件獲得編

**作成日**: 2026-05-11
**作成者**: Claude (advisor 視点)
**目的**: 新規コンサル案件の獲得（SEO 改善・サイト完成・営業導線整備）。納期なし、最速で1個ずつ消化する用。
**前提**: みんなのWA = コンサル案件の**獲得源（営業導線）**として位置づける。

---

## 戦略の骨子（先に結論）

由井辰美さん本人（CEO）にしかできない仕事は次の4種類しかない。これ以外（コード実装・記事執筆・画像生成・データ集計）は Claude / Codex / 各エージェントに渡せる。

| CEO 専属領域 | 理由 |
|---|---|
| **顔出し・実名・実在の信頼** | 異業種交流会の主宰者・クライミング歴30年という人格は CEO 本人にしか発揮できない |
| **対面/オンライン商談** | 価格交渉・契約締結は意思決定権限が要る |
| **既存リレーションの動員** | みんなのWA 会員・地元企業・クライミングジム業界の知人ネットワーク |
| **最終承認（Go/No-Go）** | 公開コンテンツ・契約・金額のサインオフ |

このロードマップは**上記4領域に絞った CEO 専属タスク**だけを並べる。実装や原稿生成のタスクは入れない（それは私や各エージェントの仕事）。

## 消化の進め方

1. **上から1個ずつ消化する**。並列実行しない（CEO の集中を切らさないため）。
2. 各タスクの開始時に、Claude が**叩き台・候補リスト・テンプレート**を `work/` に用意する。CEO は判断・承認・送信だけに集中する。
3. 完了したタスクはこのファイル内のチェックボックスを潰す（後で `[x]` 化）。
4. 詰まったタスクがあれば飛ばして次へ。後でまとめて再開する。

## CEO がやらないでいい仕事（明示しておく）

以下は Claude / developer / writer / marketer に振る。CEO は最終承認だけ。

- コード実装・修正（developer / Codex）
- 記事・LP コピー執筆（writer）
- 画像・バナー作成指示書（designer）
- 競合調査・市場調査（advisor / Codex）
- 経費・売上集計（cfo）
- タスク進捗管理（pm）
- メール下書き・DM テンプレ（writer / secretary）
