# Task #4: コンサルサービスメニュー・価格レンジ案

**目的**: 「何を売るのか・いくらで売るのか」を確定する。価格決定権は CEO 専属。
**所要**: 2時間（CEO の価格判定・市場感確認）

---

## サービスメニュー候補（5本立て・推奨構成）

### M1: Web サイト診断（入り口商品・低単価）
- **内容**: 既存サイトの SEO・UX・モバイル対応・速度・LLMO 対策を診断、改善提案書を提出
- **納品物**: 診断レポート（PDF 10〜20ページ）+ 30分のオンライン解説
- **価格レンジ**: ¥30,000 〜 ¥50,000
- **狙い**: 営業の入り口。安価で信頼を獲得 → 上位メニューへ繋ぐ
- **作業時間**: 4〜6時間（Claude 並列で診断・CEO 監修）

### M2: SEO 改善実装（中核商品）
- **内容**: 診断結果に基づき、構造化データ・メタタグ・コンテンツ・LLMO 最適化を実装
- **納品物**: 改善された Web サイト + 3ヶ月後の効果測定レポート
- **価格レンジ**: ¥300,000 〜 ¥800,000（規模で変動）
- **狙い**: 主力収益源
- **作業時間**: 1〜2ヶ月（developer + writer + Claude）

### M3: Web サイト構築・リニューアル（高単価）
- **内容**: ゼロから構築、または全面リニューアル。Next.js + Supabase + Vercel 構成
- **納品物**: 完成サイト + 運用マニュアル + 1ヶ月の伴走サポート
- **価格レンジ**: ¥800,000 〜 ¥3,000,000（機能規模で大きく変動）
- **狙い**: 大型案件・実績ショーケース化
- **作業時間**: 2〜4ヶ月

### M4: 月額顧問契約（継続収益）
- **内容**: 月1〜2回の経営+Web 相談、月1本のブログ・SNS 戦略支援、Google Analytics 月次レポート
- **納品物**: 月次レポート + Slack/LINE での随時相談
- **価格レンジ**: ¥50,000 / 月 〜 ¥150,000 / 月
- **狙い**: 安定収益・長期リレーション
- **作業時間**: 月10〜20時間

### M5: 業界特化パッケージ（限定商品）
- **クライミングジム特化**: 予約システム + 月会員管理 + Instagram 連携 = ¥500,000 一括
- **エステサロン特化**: 予約 + LINE連携 + ブログ + LP = ¥400,000 一括
- **工務店特化**: 施工事例ギャラリー + 問い合わせフォーム + ローカルSEO = ¥350,000 一括
- **狙い**: 業界特化で「何屋に頼めばいいか分かる」状態を作る
- **作業時間**: パッケージ化で1ヶ月以内に納品

| サービス | 市場相場（地方中小向け） | 推奨価格 | ポジション |

| Web 診断 | ¥20,000〜¥100,000 | ¥30,000〜¥50,000 | やや低め（入り口商品なので） |
| SEO 改善 | ¥200,000〜¥1,500,000 | ¥300,000〜¥800,000 | 中位 |
| サイト構築 | ¥500,000〜¥5,000,000 | ¥800,000〜¥3,000,000 | 中〜上位 |

| 業界特化パッケージ | (相場形成途上) | ¥350,000〜¥500,000 | 業界特化で差別化 |

- 滋賀・彦根の地方相場は東京の 6〜7割
- 由井辰美さんの実績（9事業実装済み）と業界知識で**中位以上の価格設定が正当化される**
- 入り口商品（M1）を安価にして導線を作るのが定石

## 価格決定の論点（CEO に判断を仰ぐ）

### 論点1: 入り口商品の価格
- 案A: ¥30,000（広く取る・薄利多売）
- 案B: ¥50,000（質を担保・成約率重視）
- 案C: ¥0（無料診断・LP導線で量を稼ぐ）

### 論点2: SEO 改善のレンジ幅
- 案A: ¥300,000 固定（パッケージ化）
- 案B: ¥300,000〜¥800,000（規模で変動・要相談）
- 案C: 完全カスタム見積もり（毎案件提案）

### 論点3: 月額顧問のミニマム
- 案A: ¥50,000 / 月（広く取る）
- 案B: ¥100,000 / 月（質重視）
- 案C: 月額制廃止（プロジェクト都度）

### 論点4: 業界特化パッケージを出すか
- 案A: 出す（M5）— 業界別の差別化が明確
- 案B: 出さない — カスタム見積もりに統一
- 案C: 一部だけ出す（クライミング業界のみ等）
