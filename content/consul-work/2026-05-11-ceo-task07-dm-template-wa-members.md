# Task #7: みんなのWA 会員向け「Web 困りごと無料相談」DM テンプレ

**目的**: 既存リレーション動員。会員5人に DM して反応を見る。
**所要**: CEO の作業は「送る相手を5人選ぶ」+ 送信のみ（30分〜1時間）
**前提**: Task #1（肩書き）+ Task #4（サービスメニュー）+ Task #5（連絡導線）が確定していると最強。未確定でも仮置きで送れる。

## 送る相手の選定基準（CEO 判定）

**狙いやすい会員の特徴**:
1. Web サイトを持っているが、最近更新が止まっている
2. SNS や LINE 公式を始めたいと言っていたことがある
3. 親しい関係で「ちょっと聞いてもらおう」と思える距離感
4. 中小企業オーナーで意思決定が速い
5. みんなのWA 内で活発に発言・参加している

**避けたほうがいい相手**:
- ライバル業種（コンサル業・Web 制作業）
- 関係性がまだ浅すぎる新規会員
- 過去にトラブルがあった相手

---

## CEO の作業手順

1. **送る相手5人をピックアップ** ← CEO 専属（関係性の判断）
2. パターン①/②/③ から相手に合わせて選択
3. テンプレの〇〇に名前を入れて送信
4. 返信が来たら Task #5 で決めた連絡導線（メール/LINE）に誘導
5. 面談日が決まったら `work/consulting-meetings-YYYY-MM-DD.md` に予定を記録

---

## 想定される反応と対応

| 反応 | 対応 |
|---|---|
| 「ぜひお願いします」 | 即日程調整 → 30分相談 → そのままサービスメニュー紹介 |
| 「興味あるけど今は忙しい」 | 1ヶ月後に再連絡することを伝える / リスト保存 |
| 「うちはサイトないんですよ」 | 「サイトをこれから作る相談でもOK」と返す → 構築案件化 |
| 返信なし | 1週間後に1回だけリマインド → それでも無反応なら離脱 |
