# Task #9: 会員企業5社向け「Web 改善提案 無料DM」テンプレ

**目的**: みんなのWA 会員企業の Web サイトを5社ピックアップ、改善提案を DM で送る。
**所要**: CEO の作業は「5社選定」+ Claude が作る改善案を確認 + 送信（合計1〜2時間）

---

## 進行フロー（CEO ↔ Claude の役割分担）

| ステップ | 担当 | 内容 |
|---|---|---|
| 1. 候補5社の選定 | **CEO** | 会員企業の Web サイトを見て、改善余地が大きい5社を選ぶ |
| 2. 各社のサイトURLを Claude に渡す | CEO | URL を [work/](work/) に書く or チャットで伝える |
| 3. 各社の現状診断 | **Claude / Codex** | SEO・モバイル対応・速度・LLMO の観点で診断 |
| 4. 改善提案DMの下書き作成 | **Claude / writer** | 1社ずつカスタム化したDM文を作成 |
| 5. CEO が確認・修正 | **CEO** | トーン・関係性に合わせて調整 |
| 6. 送信 | **CEO** | LINE / メール / みんなのWA メッセージ |

---

## 5社選定の基準（CEO 専属判定）

**選びやすい企業の特徴**:
1. **サイトはあるが SEO が弱い**（Google 検索で社名以外で出てこない）
2. **モバイル表示が崩れている / 遅い**
3. **更新が半年以上止まっている**
4. **問い合わせフォームがない or 古い**
5. **同業他社に Web で負けている自覚がありそう**
6. **関係性がそれなりに濃い**（門前払いにならない距離感）

**避けたほうがいい相手**:
- 既に Web 制作会社と契約中
- 関係性が薄すぎて怪訝に思われるリスク
- 営業色を嫌う性格の経営者

```

気になった点が3つほどあったので共有させてください。

[ ここに Claude が診断結果から3点を簡潔に書く ]
例:
1. Google 検索で「〇〇市 〇〇業」で検索すると、競合の□□社が
   上位に出ていて、〇〇さんのサイトは2ページ目以降になっています。
   原因はメタタグと構造化データの未設定です。

2. スマホで見ると、トップ画面のメニューが横にはみ出していて、
   タップしづらい状態になっています。

   問い合わせた人が「届いてるのかな？」と不安になっている可能性があります。

これらは私が普段やっている SEO 改善・サイト整備で

もしご興味があれば、30分のオンライン無料相談で
もう少し詳しくお話できます。営業ではなく、まずは現状の
ヒアリングと改善余地のご説明だけです。

ご都合いかがでしょうか。

由井辰美
goodbouldering@gmail.com
```

## カスタム化のテンプレ要素

各社向けに以下を Claude が埋める:

| 要素 | 例 |
|---|---|
| 関係性に応じた書き出し | 「〇〇さん」/「〇〇社長」/「〇〇様」 |
| 業界固有の検索キーワード | 「彦根 工務店」「滋賀 エステ」など |
| 競合社名 | 同業他社の実例（差し障りなく書く） |
| 具体的な改善ポイント3つ | サイトを実際に診断した結果 |
| 想定改善効果 | 「検索順位が3ヶ月で◯位 → ◯位になる見込み」など |
