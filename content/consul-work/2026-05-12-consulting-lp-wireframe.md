## デザイン方針（designer 向け指示書）

### カラーパレット
- メイン: 黒（#0A0A0A）
- アクセント1: クライミングのチョーク・オレンジ系（#FF6B35）
- アクセント2: 滋賀の自然・濃緑（#1B4332）
- 背景: 白（#FFFFFF）+ ライトグレー（#F5F5F5）

### フォント
- 和文: Noto Sans JP（Bold + Regular）
- 欧文: Inter
- 数字強調: Inter Bold で数字部分のみ大きく

### 写真・ビジュアル
- ヒーロー: Task #2 で撮影した「クライミング中」or「PC作業中」
- About: Task #2 のバストアップ写真
- 実績: 各事業のスクショ（Cloudflare R2 or Supabase Storage に保存）
- アイコン: Lucide Icons または Heroicons の無料アイコン

### レイアウト原則
- モバイルファースト（375px 基準で設計）
- 余白多め（情報詰め込みすぎない）
- CTA ボタンは画面上部・中部・下部の3箇所に必ず配置
- ファーストビューで「何屋か」と「申込ボタン」が見える

### 実装メモ（developer 向け）
- Next.js App Router
- メタタグ・OGP・構造化データ（JSON-LD: Person / Service / FAQPage）必須
- Speakable Specification も入れる（AI 検索対策）
- Lighthouse スコア 90+ を目標
- Vercel Image Optimization で自動 WebP
- フォーム送信は Server Action → Supabase + Resend
