## Gmail フィルタ設定手順（CEO 作業 3分）

1. Gmail → 設定（歯車） → 「すべての設定を表示」
2. 「フィルタとブロック中のアドレス」タブ → 「新しいフィルタを作成」
3. 検索条件:
   - 件名に「コンサル」「相談」「お問い合わせ」「Web改善」「SEO」のいずれかを含む
4. 適用: 「ラベルを付ける: コンサル問い合わせ」+ 「スターを付ける」
5. 保存

これで重要な問い合わせを見落とさない。

## フォーム実装要件（developer 向け）

### 必須フィールド
- お名前（必須）
- 会社名（任意）
- メールアドレス（必須）
- 電話番号 or LINE ID（任意）
- ご相談内容（必須・テキストエリア300文字以上）
- どこで知りましたか?（任意・選択肢: 検索/紹介/SNS/みんなのWA/その他）

### 実装スタック
- Vercel Serverless Function (`api/contact.js`)
- Supabase テーブル `consulting_inquiries`（schema: `consul` または `public`）
- Resend で CEO に通知メール + 申込者に自動返信
- reCAPTCHA v3

### 設置先
- minanowa.com の「Webコンサル」セクション
- 各事業 LP（実績紹介ページから誘導）
- 将来作る専用コンサル LP

### Supabase スキーマ案
```sql
CREATE TABLE consulting_inquiries (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  created_at timestamptz DEFAULT now(),
  name text NOT NULL,
  company text,
  email text NOT NULL,
  phone text,
  source text,
  message text NOT NULL,
  status text DEFAULT 'new',  -- new / replied / closed / lost
  notes text
);

CREATE INDEX idx_consulting_inquiries_status ON consulting_inquiries(status);
CREATE INDEX idx_consulting_inquiries_created ON consulting_inquiries(created_at DESC);
```
