## 接続戦略（優先順位順）

### 優先度1: 即着手・コスト低い

1. **彦根商工会議所 専門家登録**
   - 商工会議所には会員企業の相談に応じる「専門家派遣」制度がある
   - 「IT・Web専門家」として登録すると相談が回ってくる
   - 登録費: 無料〜数万円程度
   - 由井さん作業: 申請書記入（30分）+ 面談（必要に応じて）

2. **IT導入補助金 IT導入支援事業者登録**
   - 国の制度。登録すると補助金対象案件として顧客に提案できる
   - 顧客の Web 改善が補助金で 1/2〜2/3 補助される = 受注しやすい
   - 由井さん作業: 申請書類記入（2時間〜半日）+ 審査待ち

### 優先度2: 中期で効果が出る

3. **しが産業支援プラザの IT 専門家登録**
   - 県全域の中小企業からの相談が回ってくる
   - 由井さん作業: 登録申請（1時間）

4. **彦根商工会議所のセミナー講師打診**
   - 「中小企業のための Web 経営 5つの基本」など
   - 講師料が出る + 受講者が顧客候補化
   - 由井さん作業: 商工会議所への提案書 + 講師実績作り

5. **青年会議所・ロータリーへの参加検討**
   - 入会費・年会費は高め（年20〜50万）
   - リターン: 月1〜2回の会合で経営者と継続接点
   - 判断基準: 1〜2年で1〜2件成約すれば回収可能

### 優先度3: 長期戦略

6. **滋賀銀行系（しがぎん経済文化センター）との接続**
   - 取引先紹介は強力。ただし接点を作るのに時間がかかる
   - みんなのWA で経営者ネットワークを広げ、銀行員に紹介を頼む形が現実的

7. **公募・入札の継続ウォッチ**
   - 彦根市・滋賀県の Web 関連発注を継続チェック
   - 単発案件だが実績化に有効
