# Task #22: エステ・美容業界向けポジショニング

**目的**: 美容業界へのコンサル営業の差別化軸を確立
**前提**: Notエステの実装ノウハウを横展開する

---

## エステ・美容業界の Web 課題（業界一般）

### よくある問題
1. **テンプレ感のあるサイト**（業界共通の似たようなデザイン）
2. **施術メニューが古い**（更新が止まっている）
3. **予約導線が貧弱**（電話のみ・LINE 友だち追加のみ）
4. **キャンペーン情報が分散**（Instagram にあるが Web にない等）
5. **Before/After 写真の見せ方が下手**
6. **口コミ・お客様の声が少ない**
7. **モバイル対応が雑**（タップしにくい・遅い）
8. **AIマッチング・診断ツールがない**
9. **常連向けの会員ページがない**
10. **多店舗展開時の本部 / 店舗権限分離ができていない**

---

## 差別化軸（由井さんが取りに行くポジション）

### 軸①: 「経営者目線」のエステコンサル

普通のエステ専門 Web 業者: デザイン重視 / 業界文化に染まっている / 「キラキラ」感を作る
**由井さん**: 9事業経営の知見 × 「数字根拠必須」 × 業界の外の視点

- 「他のエステ Web 業者と違うのは、私が他の8業種も見ているから、業界外のベストプラクティスを持ち込めること」
- 「集客数字・売上に直結する Web 設計」

### 軸②: AI × エステ業務

- AI 診断ツール（肌質・体質質問 → おすすめメニュー提案）
- AI チャットボット（LINE で営業時間外も対応）
- AI 自動投稿（Instagram の予約投稿 + AI による画像加工）

実例: Not エステに導入予定として LP に明記可能

### 軸③: LINE 公式 × Web の業務連携

- LINE 友だち追加 → 自動カウンセリング → 予約までを Bot で完結
- LINE で施術リマインダー・誕生日クーポン自動配信
- 来店履歴データを Supabase に蓄積し、CRM 化

実例: Not エステの line-crm 構成

### 軸④: 多店舗展開向けスケーラブル設計

- 1店舗から始めて、2店舗目・3店舗目まで同じ CMS で運用可能
- 店舗別ページ自動生成（テンプレ + DB）
- 本部 / 店舗の権限分離

中長期的な拡大を見据えるオーナーに刺さる軸
