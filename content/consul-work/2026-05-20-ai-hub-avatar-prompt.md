# AIハブ 講師紹介アバター画像 — 生成プロンプト

## 用途
TOPページ・講師紹介セクション右側の円形アバター（200×200px相当）。
現在は絵文字 🧑‍🏫 がフォールバック表示。アニメ化肖像画像を用意して差し替え。

## 差し替え方法
1. 下記プロンプトで画像を生成（ChatGPT/DALL-E/Nano Banana/Gemini 等）
2. 生成画像を Supabase Storage `ai-hub-public` バケットなどにアップロード
3. `ai-hub/content/speaker.md` の frontmatter `avatar_url:` に画像URLを記載
4. ビルド (`python site/build_site.py`) → push → 数分でVercel本番反映

## 推奨プロンプト

### A. シンプル版（写真不要・ゼロから生成）

```
日本人男性、60代、優しい笑顔。クライミング歴30年のAI講師・経営者。
アニメ風の肖像画（ジブリ風 or 新海誠風、シンプルな線画+フラットカラー）。
正方形・上半身。背景は淡いブルー〜白のグラデーション。
シャツはネイビーかライトグレーのカジュアル襟付き。
明るく信頼感のあるトーン。
```

### B. 写真ベースのアニメ化（既存の本人写真がある場合）

```
この写真をアニメ風（ジブリ/新海誠系）に変換してください。
表情と特徴は保ったまま、線画+フラットカラーで上半身正方形。
背景はAIハブのブランドカラー(#2563eb=ブルー)の淡いグラデーション。
```

### C. キャラ化版（より親しみやすく）

```
クライマー兼AI講師の中年男性キャラ。漫画/アニメ風。
眼鏡 or 帽子で個性を出す。手にノートPCかチョークバッグ。
背景は #eff6ff (ライトブルー)。正方形・上半身・フラットカラー。
プロフェッショナルだが堅くなりすぎない雰囲気。
```

## 仕様要件
- **アスペクト比**: 1:1（正方形）
- **推奨サイズ**: 600×600px 以上（CSS で `object-fit:cover` 表示）
- **形式**: WebP / PNG / JPG どれでも可（WebP推奨）
- **背景**: 透明背景は不要（円形クリップされるため）
- **ブランドカラー**: `--primary: #2563eb` / `--primary-bg: #eff6ff` と調和する青系が望ましい
