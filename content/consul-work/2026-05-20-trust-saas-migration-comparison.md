## 2. トラストの要件 vs 各SaaSの対応

トラストの要件は[トラスト.md](../トラスト.md)＋[home-shift APPLY_GUIDE](../../トラスト/supabase/home-shift/APPLY_GUIDE.md)から:

| トラスト要件 | らくしふ | ほのぼの | ケアコラボ | 残るカスタム実装 |
|---|---|---|---|---|

| **配置基準遵守チェック**（夜勤・配置基準） | ✅ 「最低基準遵守」明記 | 不明 | ❌ | らくしふで代替可 |
| **シフト希望 LINE 入力**（家族コミュ含む） | ✅ LINE WORKS連携 | ❌ | ❌ | **要カスタム or 別途LINE Bot** |

| **共同生活援助の業務記録** | ❌ | ✅ 主機能 | ✅ 支援記録機能 | ほのぼので代替可 |
| **支援記録・申し送り** | ❌ | ✅ | ✅ タイムライン機能 | ほのぼの or ケアコラボ |

| **公式サイト（trustagent2015.com）の運営** | ❌ | ❌ | ❌ | **要カスタム維持（軽微）** |

### 結論: トラスト戦略Cハイブリッド構成案

```
┌─────────────────────────────────────────────────┐
│ トラスト 戦略Cハイブリッド（advisor 提言の具体化）  │
├─────────────────────────────────────────────────┤
│ ① らくしふ（月額未公開）                          │
│    → シフト管理・配置基準・LINE WORKS通知         │
│ ② ほのぼの（5年使用権・金額未公開）                │
│    → 業務記録・利用者情報・法令対応               │
│ ③ 軽微なカスタム保守（後継エンジニア or 由井継続）  │
│    → ・公式サイト（trustagent2015.com）           │
│    　・シフト希望のLINE収集Bot（要再評価）         │
│    　・Anthropic APIによるシフト自動生成（撤退候補）│
└─────────────────────────────────────────────────┘
```

**③の「カスタム部分」を最小化できれば、後継エンジニア負担が劇的に軽くなり譲渡確率が上がる**。
特に Anthropic API シフト自動生成は「あれば便利だが必須ではない」機能なら廃止検討の価値あり。

## 4. 意思決定の論点（advisor 提言の補強）

### 論点A: そもそも戦略Cハイブリッドへ切り替えるか

| 判断軸 | 切替する理由 | 維持する理由 |
|---|---|---|
| 24時間SLA | 大手SaaS（ほのぼの71,900事業所）にリスク移譲できる | カスタムなら自分で監視可（だが撤退できない） |
| クライアント受容性 | 介護業界では「ほのぼの」は名前で通る | カスタムシステムへの愛着・業務フロー最適化 |
| 撤退タイムライン | 2029 Q2 までに実現可能 | 後継エンジニアが見つからなければ無限延長 |
| 既存投資 | sunk cost（捨てられる） | 既に Supabase migration・LINE Bot 実装済 |

→ **撤退タイムライン重視なら切替が圧勝**。トラスト1事業のためだけに2030年以降も保守を続けるリスクの方が遥かに大きい。

### 論点B: 切替のタイミング

| 案 | タイミング | リスク |
|---|---|---|
| 即時 | 2026 Q3 | 開発投資の sunk cost が大きい・トラスト側準備不足 |
| **段階的** | **2026 Q4 〜 2027 Q2** | **クライアント業務移行を丁寧に・現場スタッフ17名の再教育を計画化** |
| 撤退直前 | 2028 Q4 〜 2029 Q1 | 駆け込み移行で品質リスク・後継候補にも提示できない |

→ **段階的（2026 Q4〜2027 Q2）が現実解**。

### 論点C: クライアント（株式会社トラストエージェント）への打診タイミング

advisor 提言「今週中に非公式打診のアポを取る」が正しい。理由:
- トラストエージェント側の不動産本業も忙しいので意思決定に時間がかかる
- 早く打診するほど反対意見も含めて知ることができ、計画が現実的になる
- 福祉本稼働（2026-08予定）の前に方向性を握っておく必要

## 5. CEO への提言

### 結論
1. **戦略Cハイブリッド（らくしふ＋ほのぼの＋軽微カスタム）への切替を 2026-Q3 内に内部決定する**
2. **トラストエージェント代表（臼井氏）への非公式打診を今週中にアポ取りする**（advisor 提言と一致）
3. **3SaaS のうち、優先問い合わせは「らくしふ」と「ほのぼの」**（ケアコラボはカバー率低・後回し可）
4. **カスタム保守を最小化する設計**を後継エンジニア譲渡前提で組む。Anthropic API シフト自動生成の廃止判断は早期に
