# グッぼるSEO低下 — GSC API実データによる確定診断

- 日付: 2026-05-25
- 取得方法: **GSC API直叩き**（google_ops基盤・認可完了後の初実データ）
- 対象: `sc-domain:goodbouldering.com`（本店ドメインプロパティ）
- 担当: Claude（consul本部・単独）

## 結論（確定）

CEOの「クライミングシューズSEOが落ちた」という実感の正体は:
**シューズページ固有の問題ではなく、グッぼる本店ドメイン全体の平均掲載順位が
6週間かけて 5.9位 → 7.1位 へジワジワ悪化している現象**だった。

- ❌ 特定ページの急落ではない
- ❌ ある日のガクッとした急落でもない
- ✅ ドメイン全体の連続的・緩やかな順位低下

## 真因 = Googleコアアップデート（確定・2026-05-25 追加検証で断定）

3つの追加検証ですべて「外部要因（コアアップデート）」を指し、技術事故/特定ページ事故を棄却した。

### 検証① コアアップデート公表日との突合（強相関）
- **March 2026 Core Update: 3/27〜4/8**（12日間・例年より変動大とSearch Engine Land報）
- **May 2026 Core Update: 5/21〜**（ロールアウト中）
- グッぼるの下落カーブ: 3/28(5.9位)→4月下旬(6.5〜7.0)→5月(7.0〜7.4)で低位安定
- **3月コアアップデート期間中から悪化が始まり戻っていない**。タイミング一致。

### 検証② ページ軸の期間比較（全種別が下落＝特定ページ事故でない）
1000ページ中386ページが順位下落。下落は商品ページ(pid=)・グループ(grp)・カテゴリ(cate)・トップ(/)と**ページ種別を問わず全面的**。最大クリック減は個別商品ページ群(298→120 等)。

### 検証③ デバイス/検索面/国の3軸（技術要因を棄却）
- **デバイス**: MOBILE 5.8→6.7 / DESKTOP 7.3→7.5 / TABLET 6.0→6.7 = **均等下落**。モバイル偏重なら CWV/技術要因だが均等なので技術ではない
- **検索面**: PRODUCT_SNIPPETS が 7.4→8.9・**クリック5071→2417でほぼ半減**（最大の出血点）。商品リッチリザルトの評価が引き下げられた
- **国**: 日本(主戦場)6.1→6.9・海外も軒並み下落 = サイト全体の評価変動

→ **結論: 3月+5月のGoogleコアアップデートによる品質評価引き下げ。** 技術事故・特定ページ事故・canonical問題ではない。

## 打つべき対策（コアアップデート被弾時の定石）

コアアップデートは「個別の技術修正」では戻らない。Googleの「品質評価」を上げる施策が本筋:

1. **E-E-A-T強化（最優先・グッぼるの武器）**: クライミング歴30年オーナーの権威性、年間300件フィッティング実績、実店舗13年——これらを**商品ページ/カテゴリページに構造化して明示**。著者情報・運営者情報・一次体験レビューを厚くする
2. **PRODUCT_SNIPPETS の立て直し**: 最大出血点。商品ページの構造化データ(Product/Offer/AggregateRating)を点検し、価格・在庫・レビューを正確にマークアップ。リッチリザルトの表示要件を満たし直す
3. **薄いページの整理 or 統合**: 386ページ下落の中に中身の薄い商品ページが混じるなら、noindex or 統合でサイト全体の平均品質を上げる
4. **競合SERP実見**: 上位下落クエリ（クライミングパンツ/ロープ/チョーク）で実検索し、上位を取った競合が何を強化したか分析
5. **次回コアアップデートを待つ**: コアアップデート被弾は次回更新時に回復することが多い。施策を打って5/21〜の更新と次回更新での回復を観測
