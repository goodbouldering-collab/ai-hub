## 依頼背景の要約

「デザイン工務店」という表現が社名（N-"デザイン"）と重複してくどい、と CEO が違和感を持っている。だが「工務店」単独ではインパクト不足。さらに強み見出し「リフォームは、設計から考える。」が当たり前すぎると感じている。一方で「デザイン工務店」はサイト全域（ヒーロー/強み/サービス/フッター/メタ/ブログ）に埋め込まれ、**SEO の準指名キーワードとして機能している可能性**があり、全置換は検索流入を毀損するリスクがある。本提案はこの板挟みを「見える化粧」と「裏のSEO」に分離して解く。

### 外部文脈

- 業界の検索行動では「リフォーム会社 vs 工務店 vs リノベ専門店 どこに頼む」という**比較・指名前段階**の検索が一定数ある。N-デザインのヒーロー「どこに頼めば？まずここへ」はこの検索意図に的中している。
- 「デザイン工務店」は世間に定着した一般名詞ではなく、**N-デザインが記事01で自ら定義している準・造語**（"新しい考え方として『デザイン工務店』という言葉を使っています"）。＝検索ボリューム自体は小さい想定。**指名検索「N-デザイン」とのセットで効く語であって、単独の集客エンジンではない**（推測・要GSC実測）。

## オーナーの「しっくり来ない」の正体（論点分解）

| 仮説 | 内容 | 判定 |
|---|---|---|
| A. 社名との重複感 | 「N-**デザイン**」＋「**デザイン**工務店」で"デザイン"が二重 | **これが主因**。特にヒーローバッジで社名想起の直後に出ると視覚的にくどい |
| B. 一般名詞すぎる | 「工務店」が没個性 | 副次的。ただし「デザイン工務店」自体は一般名詞ではなく造語なので、ここは誤認に近い |
| C. 差別化が弱い | 「設計から考える」が当たり前 | **強み見出しに関しては主因**。「設計から考える」は競合も言う |

**結論（正体）**: ヒーロー/フッターの違和感は **A（"デザイン"の二重）**。強み見出しの違和感は **C（差別化弱）**。**B（一般名詞）ではない**。
→ 処方箋は2つ：**(1) "デザイン"の重複を視覚から消す** + **(2) 強み見出しを"設計から考える"より一段尖らせる**。そして最大の未活用資産＝**「不動産×工務店の両面」を差別化の主役に昇格させる**。

## 推奨案（advisorの結論）

**方向B（表裏分離の折衷）を推奨する。逃げの折衷ではなく、これが構造的に正しい。**

1. **失う流入が定量的に限定される**。「デザイン工務店」依存記事は13本中4本（約31%）、しかもそのうち柱記事01以外の3本は keywords に1語混ざる程度。**見える化粧を外しても、検索エンジンが読む層（メタ・ブログのkeywords/metaDescription・記事01本文）を1文字も触らなければ、流入毀損は理論上ゼロ**。
2. **表と裏の語彙が割れても実害がない**。ユーザーがヒーローで「不動産×工務店」を読み、検索結果のメタで「デザイン工務店」を見ても認知不協和は起きない。**検索面では準指名語を維持、サイト面ではくどさ解消**の良いとこ取り。
3. **「設計から考える」という核フレーズは"消さずに格上げ"する**。"不動産も知っているから、設計の前に物件・お金まで考える" と前提条件を足すと、競合が言えない文になる（不動産10年＋工務店20年の経歴が裏付け）。

### 具体的にどこを触り、どこを触らないか

**【表＝刷新する】** ヒーローバッジ / ヒーローlead / 強み見出し＋本文 / フッター締め / サービス本文の "デザイン工務店" → 「不動産×工務店」軸の表現に差し替え。

**【裏＝1文字も触らない】**
- `app/layout.tsx` の title/description/keywords/OGP/JSON-LD（"デザイン工務店"を keywords 先頭で温存）
- `blog-data.ts` の記事01（柱記事・category・FAQ schema 含む丸ごと）、記事02/08/10 の keywords/metaDescription
- ＝ **検索エンジンが読む層は完全保存**

**【判断保留＝GSC実測後に決める】** 記事01のタイトル文言を将来リライトするかは、Google Search Console で「デザイン工務店」のクエリ実績を見てから。実データなしに柱記事を削るのは禁じ手。

## 「リフォームは、設計から考える。」の代替見出し案（当たり前感の脱却）

当たり前に聞こえる理由＝「設計から考える」は competitor も言える正論だから。**処方箋は「不動産（物件・お金）も含めて考える」という、経歴がないと言えない一段手前を足すこと**。

| # | 案 | 狙い |
|---|---|---|
| 1 | **リフォームは、物件選びから始まっている。** | 不動産10年の経歴でしか言えない切り口。"設計の前"を提示し当たり前感を脱却 |
| 2 | **直す前に、どう暮らすかを設計する。** | "リフォーム=工事"の常識をひっくり返す。主語転換 |
| 3 | **不動産も、設計も、施工も。住まいを「分けない」。** | ワンストップを哲学として言語化。競合が分業なのを逆手に |
| 4 | **「どこに頼めば」の、最後の相談先に。** | ヒーロー見出しと完全連動。顧客の心の声をそのまま見出しに |
| 5 | リフォームの正解は、図面より前にある。 | "設計から"を抽象度を上げて再表現、思考を促す |

**advisorの推し**:
- 強み見出し → **案1「リフォームは、物件選びから始まっている。」**（不動産軸で唯一性が最強・経歴が裏打ち）
- ヒーローバッジ → **案1「古民家再生 × 不動産も知る工務店」**
- フッター → **案4「不動産30年・工務店20年。住まいのことは、まずここへ。」**

この3点で「不動産×工務店の両面」がサイトの背骨として通り、"デザイン"の重複は視覚から消える。

## 数字根拠

- 「デザイン工務店」依存ブログ: **13本中4本（約31%）**、うち本体流入をこの語に賭けているのは柱記事01の**実質1本**。残り9本（約69%）は地名×症状ロングテールで流入取得 → **見える化粧の刷新で失う検索流入は0に設計可能**。
- 出現箇所の表裏比: 表（ユーザーが読む）約7箇所 vs 裏（検索/構造化）約32箇所 → **表だけ触れば違和感は消え、裏（流入の効く層）は保全できる**。
- 業界SEO定石: 一般語より「症状＋木造＋地名」型ロングテールが競合少・成約率高（出典: 工務店マーケ／TOPPAN refotoru）。N-デザインは既にこの型で9記事を運用 → 「デザイン工務店」一語に集客を依存していない傍証。
- **要追加調査（推測の明示）**: 「デザイン工務店」「彦根 デザイン工務店」の実際の検索ボリューム・GSC実績（表示回数/CTR/平均順位）は未取得。**柱記事01のタイトル改変可否はGSC実測を見てから**判断。GSC/GA4自動レポート基盤はコード完成済・CEO認可待ち。認可後に「デザイン工務店」クエリの実数を出せる。

## 反対意見・リスク（推奨が外れるパターン）

- **もし「彦根 デザイン工務店」が実は月数十回検索され、かつ1位を取れている**なら、表からも完全には消さず記事01への内部リンク文脈で語を残す価値がある → GSC実測で判明。それまで方向Bでも記事01・メタは温存しているので取り返しはつく（表のコピーは可逆）。
