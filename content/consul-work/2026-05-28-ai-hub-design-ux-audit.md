# 制作物: AIハブ LP UXデザイン改善指示書
## 用途
https://aiclimb.vercel.app/ のLPを、「AIにこれから触れる/興味があるだけの初心者（彦根のIT苦手な社長）」が申し込むまでの障壁を下げる。

---

## 1巡目：初心者目線の「迷い・不安・操作不明」UX問題洗い出し

### [問題A] ダークデザインの読みやすさ問題（重要度: 高）

#### 現状
- 背景: `#0B0D14`（深い夜空ネイビー）、テキスト: `#F4F6FB`、ミュート: `#6B7488`
- カード面: `rgba(20,23,34,0.62)` のガラス質感（glassmorphism）
- デフォルト dark テーマ。ライトモード切替ボタン（🌙）は右上にあるが非常に小さく（38px正方形）目立たない

#### 初心者目線での問題
ダークUI はエンジニア・デザイナー向けの先進的なシグナルを発する。
「彦根のIT苦手な社長」が初めて開いたとき、**「自分には難しそうなサービスだ」という第一印象**を植え付けるリスクが高い。
実際の問題:
- ミュートテキスト(`#6B7488`) がダーク背景上で **コントラスト比 約3.8:1**（WCAG AA基準の 4.5:1 未達）。小さい本文（13px）が読みにくい
- glassmorphism（半透明パネル）は画面描画が重い端末（古いスマホ等）でちらつく
- 夜間の使用には有利だが、昼間オフィスで使うビジネスオーナーには眩しくない・明るくない分「暗い＝不安感」に繋がりやすい

---

### [問題B] ヒーローの情報過多と優先順位の曖昧さ（重要度: 高）

#### 現状のヒーロー構成（上から順）
```
eyebrow badge（小テキスト）
h1「AIの使い方、教えます。」
sub-catch（太字強調テキスト）
lead（2行テキスト）
CTAボタン2本（「無料で30分相談する」「30秒でAIレベル診断」）
trust badges 3個（無料・補助金・9事業）
--- ここまでで初心者は既に情報を消化しきれている ---
hero-quiz（AIレベル診断 3択ボタン・常時展開）
hero-visual（SVGアニメ）
hero-flow（3ステップ帯オーバーレイ）
```

#### 初心者目線での問題
- **CTAが2本並列**（相談 vs 診断）で、「どちらを押せばいいか」の判断を迫られる。初心者ほど選択肢が増えると行動が止まる（選択のパラドックス）
- **trust badges が日本語で「9事業を回す現役オーナー」** は、初心者には「？」になりやすい。「9事業」という数字の意味が伝わらない
- **hero-quiz（診断）がヒーロー内に常時展開**されている。ファーストビューで既に「eyebrow + h1 + sub-catch + lead + CTA2本 + trust3個 + 診断3択ボタン + SVGアニメ」が詰め込まれており、IT苦手な社長が受け取る情報量として過剰
- **SVGアニメのラベル**「自動化中…」「✓ 業務完了」は日本語SVGで、初心者は「これは自社のことか、他の企業のことか、サンプルか」判断しにくい
- **「📩 まずは無料で30分相談する」** は長い（「まずは」が余計）。ボタン内テキストは短いほどタップしやすい

---

### [問題C] 受講プラン4カードの選びにくさ（重要度: 最高）

#### 現状
4カードが横並び（PC: 4列、タブレット: 2列、モバイル: 1列縦並び）
各カードに: カテゴリバッジ + 画像 + アイコン + タイトル + レベルバッジ + 時間 + 価格 + 補助金バッジ + 説明文（3〜4行） + CTAボタン

#### 初心者目線での問題
- **価格の表示形式が混在**
  - 「2,200円〜5,500円」（レンジ表記）
  - 「5,500円」（単価）
  - 「33,000円（税込・補助金対象）」
  - 「月額 100,000円（税込）× 6ヶ月」
  → 初心者が「いくらかかるか」を瞬時に理解できない。特に「月額100,000円×6ヶ月 = 総額600,000円」が補助金後いくらになるか、一目では分からない
- **「どれが自分向けか」の選択補助が弱い**。レベルバッジ（初級/中級/上級）はあるが、初心者は自分がどのレベルかを判断するための基準が不明確
- **CTAが4種類**: 「予約する（Square）」「詳細・お申込みはこちら」「開催を相談する」「導入相談（無料・60分）」→ 行動先がバラバラで統一感がない
- 最安値の「2,200円〜」が一番先に来ているのは良いが、**初心者は2,200円で何ができるかのイメージが湧きにくい**（説明文が業界用語混じり: 「LLMO / SEO / MEO / Claude Code 活用」）
- PC4列は各カードが狭く、22px padでも説明文が詰まって見える

---

### [問題D] 「ご依頼の流れ」4ステップの信頼担保（重要度: 中）

#### 現状
flow-list: 4列グリッド（PC）、各ステップに番号 + タイトル + 説明文

#### 初心者目線での問題
- ステップ名が「業務ヒアリング」「実装・コンテンツ制作」等の言葉で、初心者に「何をするかのイメージ」が湧きにくい
- **納期・費用の目安がない**。「どのくらいで終わる？」「いつ払う？」の不安が解消されない
- 「04. 納品・引き継ぎ」の後が「終わり」かどうか不明（保守・フォローへの言及なし）

---

### [問題E] 申込ボタンの視認性と到達しやすさ（重要度: 高）

#### 現状
- ヘッダーの「📩 無料相談」ボタン: グラデーション背景（青→紫）、白文字、`#contact` へのアンカー
- モバイルスティッキーCTA: 画面下部に固定表示（ヒーロー通過後に出現）、「無料相談」ボタン付き
- コンタクトセクション: メール + LINE の2択カード（`#contact`）

#### 初心者目線での問題
- **CTAボタンの色がコンテンツカードと同じグラデーション**（青→紫）を使っており、"押せるもの"と"読むもの"の区別がつきにくい場所がある
- **モバイルスティッキーCTAの文言**「無料相談はこちら」が右端ボタンに入っているが、左側の「無料相談」「30分・メール/LINE」という2行テキストとの関係が初見で分かりにくい
- **#contact セクション**にたどり着いた後、「メール」「LINE」2択を選ぶ必要がある。初心者はどちらを選ぶべきか迷う（LINE の方が心理的ハードルが低い場合が多いが、それが分かりにくい）
- **フォームがない**。メールアドレスをコピー or LINEアプリを開く必要があり、摩擦が大きい

---

### [問題F] 講師の信頼性担保（重要度: 中）

#### 現状
speaker-intro-grid: テキストエリア + 画像エリアの2列グリッド
画像エリア: `speaker-art-ph`（CSSプレースホルダ）が使われている場合がある（実画像が無ければ代替表示）

#### 初心者目線での問題
- `speaker-art-ph` が表示されると**グリッドパターンの抽象的アートが出る**（青い点線格子＋「Y」の大文字）。初心者には「講師の写真のはずが絵になっている」で不安感
- stats strip の「30年 クライミング歴」「9事業」は初心者にとって「なぜクライミング経験がAIと関係あるの？」という疑問を生む。繋ぎの説明がない
- 認定・資格・メディア掲載等の第三者証明（social proof）が弱い

## 2巡目：申込率を上げるUI/UX具体的修正案

### [修正A] デフォルトをライトモードに切り替える

**根拠**: IT苦手な中高年経営者は Webサイト = 白背景という経験学習が強固。ダーク→ライトへの切替コストより、ダークを維持することで失う初心者のの信頼の方が大きい。

**実装仕様**:
```javascript
// HEADER_JS内のテーマ初期化部分を変更
var mode = saved === 'dark' ? 'dark' : 'light';  // デフォルトを'light'に変更
```

```css
/* ライトモードを:root の デフォルトにする */
/* 現在: :root = dark, :root[data-theme="light"] = light */
/* 変更後: :root = light, :root[data-theme="dark"] = dark */
```

配色変更後の主要トークン（ライトデフォルト）:
- `--bg-base`: `#F7F8FC`
- `--bg-white`: `#FFFFFF`
- `--text`: `#0B0D14`
- `--text-soft`: `#404A63`
- `--primary`: `#5468FF`（青は維持・視認性UP）
- コントラスト確認: `--text-soft(#404A63)` on `--bg-white(#fff)` = 約8.9:1 ✅

**ダークモード**: 右上の🌙アイコンで切替可能のまま維持。エンジニア勢への配慮。

### [修正C] 受講プランの「初心者が選びやすい」レイアウト改修

**根拠**: 価格・用途の混乱解消。初心者の「自分に合うか」確認支援。

**3方向の改修**:

#### C-1. プランカードの情報整理（表示順序の見直し）

現在の順: カテゴリ → 画像 → アイコン + タイトル → レベル + 時間 → 価格 → 補助金 → 説明 → CTA

修正後: カテゴリ(レベル表示兼用) → タイトル → **1行の「誰向けか」テキスト** → 価格（補助金後の実質額も隣に） → 説明（初心者向けに業界用語を除去） → CTA

```
+----------------------------+
| 【初級】  AI個別相談 60分   |
|                            |
| こんな方向け               |
| ▸ AI、まだ触ったことがない  |
| ▸ 何から始めればいいか不明  |
|                            |
| 通常 5,500円               |
| → 補助金適用後 約1,800円   |
|                            |
| [今すぐ予約する]            |
+----------------------------+
```

「LLMO/SEO/MEO/Claude Code」等の業界用語は削除し、平易な言葉に置き換え:
- 「LLMO / SEO / MEO / Claude Code 活用」→「Google検索での上位表示・AI活用全般」
- 「RAG チャット」→「社内の書類を参照するAIチャット」

#### C-2. 価格の「実質額」を必ず表示

補助金があっても「いくら払うか」が見えなければ意思決定できない。

```css
.pkg-price-wrap { display: flex; flex-direction: column; gap: 4px; }
.pkg-price-regular { font-size: 13px; color: var(--muted); text-decoration: line-through; }
.pkg-price-effective { font-size: 22px; font-weight: 900; color: var(--emerald); }
.pkg-price-note { font-size: 11px; color: var(--muted); }
```

HTML例:
```html
<div class="pkg-price-wrap">
  <span class="pkg-price-regular">33,000円</span>
  <span class="pkg-price-effective">実質 約11,000円〜</span>
  <span class="pkg-price-note">※補助金（IT導入補助金等）適用後の目安</span>
</div>
```

#### C-3. PC: 4列→2列グリッドへ変更（初心者の可読性優先）

4列は1カードが狭く説明文が詰まる。2列なら各カードが広くなり、画像・テキストが余裕を持って読める。

```css
.packages-grid {
  display: grid;
  grid-template-columns: repeat(2, 1fr);  /* 4→2列に変更 */
  gap: 20px;
  margin-top: 12px;
}
@media (max-width: 760px) { .packages-grid { grid-template-columns: 1fr; } }
```

### [修正E] trust badges の言い換え

初心者が即座に「自分に関係ある」と感じる言葉に変える。

| 現在 | 修正後 | 理由 |
|---|---|---|
| 「9事業を回す現役オーナー」 | 「現役の経営者が直接教える」 | 「9事業」は規模感が伝わりにくい、「現役経営者」は先生との距離感を縮める |

## 修正草案まとめ: 申込率を最も上げる変更TOP3

---

### TOP1: デフォルトをライトモードに変更

**優先度**: 最高（他の修正より先に実施）

**理由（認知負荷・信頼・操作性の3軸）**:
- **認知負荷**: ダーク背景は目に飛び込む情報の輝度差が大きく、初心者が「要素の優先順位」を読み解く認知コストが上がる。ライトモードは白背景に黒文字という日常慣れした配色で、ページ構造を無意識に読める
- **信頼**: 「難しそう」という印象は初心者の離脱を招く。ライトデザインは銀行・行政・医療など信頼性の高いサービスと同じ視覚的文脈にある
- **操作性**: ライトモードでは「押せるボタン（青）」と「読む文字（黒）」のコントラスト差が明確。ダークUIでは両者が同様にコントラストを持つため、クリッカブル要素の識別が難しい

**具体的な実装内容**:
1. `build_portal.py` の `PORTAL_CSS` で `:root` のデフォルトカラー変数をライトモード値に差し替え
2. `data-theme="dark"` 属性時にダークモード値を適用するように逆転
3. `HEADER_JS` の初期化ロジックで `saved === 'dark'` 以外はライトをデフォルトに
4. `theme-color` metaタグを `#0d1126`（現在）→ `#F7F8FC`（ライト）に変更
5. ライトモード時のコントラスト確認: primary `#5468FF` on white = 5.1:1（AA合格）

---

### TOP2: 受講プランの「初心者向け言語化」と価格の実質額表示

**優先度**: 最高（申込直結セクション）

**理由**:
- **認知負荷**: 「LLMO / SEO / MEO」などの略語は、聞いたことのない初心者に「自分は対象ではないかも」という除外感を生む。平易な言葉に変えるだけで対象者の門を広げられる
- **信頼**: 価格の透明性は信頼の根拠。「補助金で安くなる」とだけ書かれていると、実際の負担がわからず申込をためらう。「実質 約11,000円〜」という具体額の提示が信頼と決断を促す
- **操作性**: PC4列から2列に変えることで1カードあたりの横幅が広がり、説明文の行数が減ってスキャンしやすくなる。「この金額でこれができる」が一視野内に収まる

**具体的な実装内容**:
1. `_render_courses_packages()` 内の各アイテムの `desc` を平易な言葉に書き換え（コード上の文字列変更のみ）
2. PKGカードに `pkg-price-wrap` / `pkg-price-regular` / `pkg-price-effective` の3要素を追加
3. 補助金後の実質額を各プランに算出・追記（目安額として表示）
4. `.packages-grid` の `grid-template-columns` を `repeat(2, 1fr)` に変更
5. 各カードの `pkg-desc` 冒頭に「こんな方向け ▸ ...」の箇条書き2行を追加

---

### TOP3: コンタクトセクションのLINE推奨明示とヒーローCTA一本化

**優先度**: 高（離脱防止）

**理由**:
- **認知負荷**: メール・LINEの2択で「どちらを押すか」に心理的エネルギーを使わせない。LINEを推奨と明示することで、迷わず1アクションで済む
- **信頼**: 「気軽に話しかけて」という言葉とLINEの緑色は「ここは敷居が低い」という感情的安心を作る。コーポレートメールだけだと「フォーマルな返信が来そうで怖い」という萎縮を招く
- **操作性**: ヒーローCTAを1本に絞ることで「最初に押すボタン」が明確になる。「診断もある」「相談もある」という同列表示は初心者の「自分はどっちをやればいいか」という躊躇を生む
