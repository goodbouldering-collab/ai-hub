# AIハブ Figma デザイン見直しメモ

日付: 2026-06-02
対象: AIハブ トップページ
Figma: https://www.figma.com/design/PWa1B5SmLOz32n6MO7iGXl

## 目的

現行の強い訴求「AIの使い方、教えます。」は残しつつ、ファーストビューを「相談したくなる順番」に整理する。

## 残す強み

- 「AIの使い方、教えます。」は初心者にも届く。難しい肩書きより入口として強い。
- 補助金申請まで伴走できる点は、滋賀・彦根の中小事業者に刺さる。
- 9事業を回す現役オーナーという実績は、講師紹介より先に信頼材料として見せたい。

## 直す詰まり

- ファーストビューに補助金、週10時間削減、AI診断、管理ログイン、3ステップが同居していて視線が散る。
- 無料相談とAI診断のボタンが近い重さで並び、主目的が少し曖昧になる。
- 右側ビジュアルは良いが、上に重なる3ステップUIと意味が重複している。
- 管理ログインは初見ユーザー向けのファーストビューから外し、ナビ配下だけでよい。

## 方針

- 入口は「無料相談」「30秒診断」「制作実績」の3択に畳む。
- 主CTAは「無料の30分相談を予約する」に一本化する。
- 週10時間削減、実質1/3以下、9事業オーナーは証拠ストリップとして横並びにする。
- ヒーロー画像は説明カードを重ねすぎず、講習の雰囲気を伝える背景兼信頼素材として使う。

## Figma に置くべきフレーム

1. Review Board
   - 残す強み / 直す詰まり / 新しい方針 / 実装順
2. Desktop Hero案
   - 1440px幅
   - 左: H1、リード、主CTA、補助CTA、証拠ストリップ
   - 右: 講習ビジュアル、薄いステップ表示
3. Mobile Hero案
   - 390px幅
   - H1、リード、主CTA、診断ボタン、証拠3点、画像の順

## 実装順

1. Hero copy/layout
   - H1、リード、CTA、証拠ストリップを整理
   - 管理ログインをファーストビューから外す
2. Packages
   - 4プランは比較表として密度を上げる
   - AI診断の結果がどのプランに着地するかを明確化
3. Works carousel
   - 代表実績だけ先に見せる
   - 詳細一覧への導線を強める
4. Mobile
   - sticky CTA と hero CTA の重複感を調整
   - 最初の1画面に本文を詰めすぎない
