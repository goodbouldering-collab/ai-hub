# YouTube「エンジニアなら、これくらいAI使えないとね。」診断素材

作成日: 2026-08-21
状態: **再利用素材として整理済み・公開ページへ反映済み**

## 公開ページへの反映状況

- 公開トップ: 「コピペで止まっていないか」「任せた仕事を確かめられるか」「うまくいった方法を次にも残せるか」の3問を、AI実践力診断への導入として掲載。
- AI実践力診断: 基礎10問の結果後に、任意の「実装編 6問」「組織導入編 6問」を掲載。
- 採点: 追加6問は各30点で別採点し、基礎10問の100点には加算しない。
- 結果: 低かった2問の次の行動と、既存の相談・講習を任意案内として表示。
- 60秒診断: 悩みから相談・講習を選ぶ役割を保つため、質問や判定は変更していない。

## 目的

[エンジニアファーストの動画](https://www.youtube.com/watch?v=92n-hUhRE58)で扱われた「AIを使っているつもりになっていないか」という論点を、AI相談の診断・相談・講習へ後から混ぜられる質問へ変換する。

動画の優劣判定や発言の逐語転載は行わない。自動生成字幕を手掛かりに、地域事業者、学校、福祉施設、個人事業主、エンジニアが自分の実務を振り返れる言葉へ再編集する。

## 動画から拾える12の疑問

1. AIとの会話やブラウザのコピペだけで、実際の仕事の流れは変わっているか。
2. ファイル、資料、ブラウザ、開発環境などを渡し、一連の仕事をAIへ任せられているか。
3. 社内規定や端末制限で使えない機能があるとき、許可範囲と代替手段を整理できているか。
4. 新しいAIツールを配る前に、対象者が価値を体験できる研修や小さな課題を用意しているか。
5. 個人情報・秘密情報・公開操作を、禁止だけでなく権限、確認、停止、復旧まで含めて管理しているか。
6. AI利用料と人の確認時間に対して、短縮時間、品質、売上、利用者価値のどれが増えたか説明できるか。
7. AIで空いた時間を、顧客対応、教育、企画、地域活動など何へ振り向けるか決めているか。
8. プロジェクト固有の目的、禁止事項、完成条件、失敗から得た学びを、次回も使える形で残しているか。
9. 過去の指示やルールが、新しいモデルの力を必要以上に縛っていないか定期的に見直しているか。
10. SNSや動画で見た新しいAI活用法を、出典、適合性、小さな検証で確かめてから取り入れているか。
11. AIに設計や実装を任せる範囲をリスクで分け、利用者シナリオ、テスト、ブラウザ確認、専門家レビューで確かめているか。
12. 要約・文章・返信をAIへ任せても、自分で説明する、異論を出す、たとえる、相手と直接話す力を残しているか。

## 反映するときの推奨順

### 1. AI実践力診断へ「追加診断」を付ける

既存10問は変えず、結果画面またはその下に次の2種類を任意で置く。

- **実装編 6問**: `V01`、`V07`、`V08`、`V09`、`V10`、`V11`
- **組織導入編 6問**: `V02`、`V03`、`V04`、`V05`、`V06`、`V12`

利用者が必要な方だけ選べるので、初心者の離脱を増やさず、エンジニアや組織の深い悩みも拾える。

### 2. 公開トップは3つの疑問だけ見せる

60秒診断は「いまの悩みから相談・講習を選ぶ」役割なので、成熟度質問を混ぜて長くしない。AI実践力診断の直前に、次の短い導入を置くのが合う。

> AIを使っているつもりで、仕事は変わりましたか？<br>
> コピペで止まっていないか。任せた仕事を確かめられるか。うまくいった方法を次にも残せるか。<br>
> **AI実践力診断で現在地を見る**

### 3. 相談・講習では質問バンクを全件使えるようにする

相談前の聞き取りでは、回答が低い質問だけを深掘りする。全問を利用者に見せる必要はない。

| 主な詰まり | 次の行動 | 既存の導線候補 |
| --- | --- | --- |
| コピペ止まり、何を任せるか不明 | 身近な仕事を一つ選び、資料を渡して成果物まで作る | AIエージェント講習 / AI無料相談 |
| 社内制約、研修不足、安全ルール未整備 | 利用範囲、禁止情報、確認者、小さな実証を決める | AI個別相談 / AI伴走支援 |
| 指示・文脈・学びが残らない | 目的、完成条件、確認手順、改善履歴を一つの場所に残す | AIエージェント講習 |
| テストや実画面確認がない | 利用者シナリオからテストと公開確認を作る | AIコーディング講習 |
| 費用だけ増え、成果が不明 | 一業務の費用、短縮時間、品質、次に増やす時間を測る | AI個別相談 / AI伴走支援 |
| AI任せで説明や対話が減る | AI案へ自分の異論・理由・相手への説明を一つ加える | AIエージェント講習 |

### 4. 発信は一つの素材から媒体別に再編集する

- YouTube: 「AIを使っているつもりを抜ける7段階」を実演する
- note・ブログ: 12問のセルフチェックと、低かった項目の改善例を書く
- SNS: 1投稿1問で12本に分け、回答より「次の一歩」を添える
- Webサイト: 3問だけ見せ、AI実践力診断へ誘導する
- 講習: 受講前後に同じ追加6問を使い、点数より成果物・確認手順・短縮時間の変化を見る
