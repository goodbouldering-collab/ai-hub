## 並列運用が「前提」になった三点セット

2026年前半のClaude Codeは、要するに**1人で何セッションも同時に走らせる**方向に全振りした。ここが効く。

### バックグラウンドセッション `claude --bg`

ターミナルを開きっぱなしにしなくてもタスクを走らせられる。監督プロセスが裏で面倒を見る方式。Q1からじわじわ育って、**研究プレビューとして固まったのは4月（Week 15, v2.1.92系）**。会話の途中からは `/bg` で送れる。

`--bg` 単体だと「投げっぱなしで放置」になりがちなので、後述の Agent View と `/goal` とセットで初めて意味が出る。単独で使う機能ではない、というのが触ってみての結論。

### Agent View `claude agents`

**5月（Week 20, v2.1.139系）**で入った、全セッションを1画面で見るやつ。スラッシュ無しの `claude agents` で起動する。各セッションの状態（作業中 / 入力待ち / 完了）が一覧で出て、その場で dispatch・peek・attach/detach できる。

並列を3本も4本も走らせると「どれが今止まってて待ってるのか」が分からなくなるのが従来の最大の苦痛だった。それが1画面で解消された。`--bg` を本気で使うなら、これが来てからが本番。

### `/goal` — 完了条件を渡して自走させる

同じく**Week 20**。完了条件を渡すと、それが満たされるまでターン跨ぎで回り続ける。経過時間・ターン数・トークン数がライブで出るので「どこまで燃やしたか」が見える。

`--bg` + `/goal` の組み合わせが、夜間バッチ的な開発の核になる。「テストが全部通るまで」「lintとtypecheckがクリーンになるまで」を条件にして放流する使い方が一番ハマる。

## 権限まわり — 「全許可」と「全確認」の間が埋まった

ここが地味だが一番大きい。今までは `--dangerously-skip-permissions`（全許可）か、毎回確認かの二択で、現実的な落とし所がなかった。

### Auto Mode（`auto` 権限モード）

**3月（Week 13, v2.1.83系）**の研究プレビュー。安全な操作は自動承認、リスクのある操作はブロック、という判定を分類モデル（Sonnet 4.6）が裏でやる。「全部YOLOで許可」の恐怖と「毎回Enter」の苦行の中間がようやく来た。

### `autoMode.hard_deny`

**5月（Week 19, v2.1.136系）**。分類器に対して「これは無条件で蹴る」という固いルールを `settings.json` の `autoMode.hard_deny` 配列で渡せる。Auto Mode の判定がどれだけ賢くても、`rm -rf` や本番DBへの書き込みみたいな**絶対に触らせたくない操作**は機械的に止める、という保険。

※ ネット上で "hard deny rules" という呼び方を見るが、公式設定キーは `autoMode.hard_deny`。全部を事前許可リストでしか通さない `dontAsk` モードも別にある。

## 効かせどころを選ぶ — Opus 4.7 と `/effort`

**4月（Week 16）**でOpus 4.7が来て、Max/Team Premium ではこれが既定に。あわせて推論の効かせ具合を選ぶ `/effort` がスライダーUI化され、最上位の `xhigh` が増えた。`${CLAUDE_EFFORT}` 環境変数でskillやbashからも現在値が読める。

全タスク `xhigh` で回すのはトークンの無駄。難所だけ `xhigh`、定型は控えめ、と**1セッション内で出し入れする**のが正しい使い方。

## クラウドと手元の往復 — Ultraplan / Monitor / `/loop`

- **Ultraplan**（Week 15）: 計画をクラウドで下書き → Web エディタでレビュー → 手元かリモートで実行。設計と実装の場所を分けられる。
- **Monitor ツール**（Week 15）: バックグラウンドのログやプロセスのイベントを会話にリアルタイムで流し込む。`--bg` で走らせたものの様子を `sleep` ポーリングせずに拾える。
- **`/loop`**（Week 15）: 定期タスクのスケジュール実行。間隔を省くと自己ペースで回る。「5分おきにデプロイ確認」みたいな常駐用途。

## プラグイン — 公式マーケットプレイスで完結させる

`/plugin`（**単数**）で Discover タブが開いて公式マーケットプレイス（`claude-plugins-official`）を閲覧・導入できる。5月時点で公式101本、コミュニティ含めると1,000本超。

Week 19 からは `.zip` アーカイブや URL からの読み込み（`--plugin-dir` / `--plugin-url`）にも対応した。とはいえ**素性の知れない拡張を入れない方針**なら、公式マーケットプレイス内で完結させるのが無難。コマンドは `/plugins` ではなく `/plugin` なので注意。

## おまけ：環境まわり

- **PowerShell ネイティブ対応**（Week 13 / Week 18）: Windows で Git Bash 必須ではなくなった。既定シェルツールが PowerShell に。
- **Computer use in CLI**（Week 14, 研究プレビュー）: GUI をクリックして、ネイティブアプリ操作で変更を検証できる。
- **`worktree.bgIsolation`**（Week 19）: バックグラウンドセッションを隔離 worktree でやるか、作業コピーに直接当てるかを選べる。

## 今が回し時、という話

**5月13日に週次上限が+50%**された（Pro / Max / Team / シート制 Enterprise 対象、無料枠は対象外）。**7月13日まで**の期間限定。SpaceX との計算資源契約が背景、という報道。

`--bg` + `/goal` + Auto Mode が揃って「放流して自走させる」開発がやっとまともに成立した時期に、上限が1.5倍。フル回転させるなら今。
