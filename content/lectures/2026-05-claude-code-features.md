## Codex初級は一つの資料で学べます

Codexへ安全に仕事を頼む初級内容は、[AIエージェント講習120分の受講資料](./2026-04-ai-kihon.html#codex-beginner)へ統合しました。

統合後の資料では、次の内容を一つの流れで確認できます。

1. 今日終わらせる仕事を1つ決める
2. Codexと人の役割を分ける
3. 作業用コピーを用意する
4. 1ファイル・1か所だけ頼む
5. 変更点と実際の画面を確かめる
6. 必要なら修正または取り消す
7. 使えた依頼文と次回手順を残す
