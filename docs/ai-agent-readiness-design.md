# AI Agent Readiness Compass — 設計メモ

作成日: 2026-08-13

## 目的

AI初心者、地域事業者、学校・福祉施設、個人事業主、若い挑戦者が、現在のAI実践力を100点・5段階で把握し、次に学ぶ内容とAI相談の既存講習へ迷わず進める独立ページを作る。

英語名は **AI Agent Readiness Compass**、日本語名は **AI実践力診断** とする。訴求文は「あなたはAIに聞く人か、任せて確かめる人か。」とし、専門用語よりも時間・品質・仕事の悩みから入る。

## 体験設計

- 公開ルート: `/ai-agent-readiness/`
- 20問、各0〜5点、合計100点。直近90日の実際の行動を共通尺度で答える。
- 1問ずつ表示し、戻る・次へ・進捗表示・キーボード操作に対応する。
- 結果は合計点、5段階、8領域、将来対応の5指標、弱い領域、次の90日目標、推奨講習を表示する。
- 回答はブラウザ内だけで計算し、サーバー送信・個人情報入力・アカウント登録を行わない。
- 結果をAI相談へ持ち込める短い相談メモとしてクリップボードへコピーできる。
- 印刷にも対応し、結果を本人の学習記録として残せる。

## 採点

共通回答尺度:

| 点 | 行動の証拠 |
|---:|---|
| 0 | 未経験、または確認せず任せている |
| 2 | 手順を見ながら一度試した |
| 4 | 確認手順と記録を残し、繰り返せる |
| 5 | 他者へ展開し、成果指標・レビュー・安全な演習で改善している |

レベル:

1. 0〜24: Explorer / AIの入口を見つける
2. 25〜44: Guided AI User / 対話で仕事を整える
3. 45〜64: Workflow Builder / 再現できる仕事の型にする
4. 65〜84: Agent Operator / 任せて検証する
5. 85〜100: Agent Orchestrator / 複数AIと仕組みを率いる

Level 5 は合計点だけでなく、8領域すべて60%以上を目安とする。実事故の経験は求めず、安全な演習や第三者レビューも行動の証拠として扱う。

安全ゲートを別に設ける。検証またはデータ・安全領域が50点未満ならレベル3まで、エージェント運用が60点未満ならレベル4までとする。合計点は変更せず、結果画面で理由を説明する。高得点でも検証・権限管理を飛ばして上位レベルと判定しないためである。

## 8領域

1. 人間中心・価値設計 / Human Purpose
2. AI基礎・文脈設計 / AI & Context Literacy
3. 検証・評価 / Verification & Evaluation
4. データ・権限・安全 / Data, Permission & Safety
5. 業務分解・価値測定 / Workflow & Value
6. コード・システム / Coding & Systems
7. エージェント運用 / Agent Operations
8. 将来適応力 / Future Adaptability

## 今後のAI指標

100点の合計とは別に、同じ回答から以下を可視化する。未来予測や市場価値の保証ではなく、変化へ備える学習指標と明記する。

- Human Oversight: 承認点・停止条件・説明責任
- Evaluation Literacy: 成功条件・テスト・失敗分析
- Portability: 仕様書・開いた形式・モデル切替に耐える成果物
- Tool-using Agent & Multimodal: 道具を使うAIと画像・音声・動画等を目的に応じて評価
- Value Creation: 時間短縮だけでなく品質・利用者価値・人の判断を測る

## 講習への導線

- Level 1: 診断専用のAI無料相談 入口整理
- Level 2: AIエージェント講習 120分 / 5,500円
- Level 3: AIエージェント講習 120分 / 5,500円
- Level 4: AIコーディング講習 120分 / 11,000円
- Level 5: AI伴走支援の詳細確認（高額な直接決済にはつなげない）

高額な伴走支援は診断結果から直接決済させず、講習一覧・相談へ案内する。現在公開先が確定していないAIホームページ講座は割り当てない。

## 動画・記事の扱い

ユーザー指定のReHacQ動画は、知能の一般化、AIの二面性、モデル切替、成果物の持ち運び、事業価値、動画・物理AIなどを考える「未来を読む」入口として要約する。ただし対談・専門家見解であり、能力判定の根拠にはしない。

動画ライブラリは指定動画、日本語の人気解説、OpenAI公式Codex入門、Microsoft公式のAI Agent体系講座、Human-on-the-loop解説を、対象レベルと選定理由付きで掲載する。再生数は変動するため恒久的な順位として表示せず、調査日と「人気は正確性を保証しない」を明記する。

埋め込みは同意後に `youtube-nocookie.com` を読み込むクリック式とし、通常リンクを必ず残す。

## 根拠と限界

OECD/EC AILit、UNESCO AI Competency Framework、NIST AI RMF/GenAI Profile、Anthropic AI Fluency・Building Effective Agents、OpenAIのエージェント実務ガイド、ILOの雇用変容研究を参考に、成人の実務向けに独自再構成する。

これは学習用セルフチェックであり、心理検査、資格認定、採用・適職判定、法令適合証明、就職・昇進・収入・成果の保証ではない。自己申告を含むため、実務力は成果物と第三者レビューでも確認する。
