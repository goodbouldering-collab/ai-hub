## 公開手順

build_orca_blog_release.pyは、本番と照合した515資産の基準から記事・画像5点を追加し、ホーム・ブログ一覧・sitemapだけ更新。他512資産とWorkerを維持。不変資産はハードリンク、編集する3文書は別コピーとし、元基準のハッシュ不変を検証する。

既存dirty作業は保全。今回だけ検証・commit・PR・統合し、中央台帳の公開元で同SHAから再生成、ガード後に公開。工程記録はtmp/delivery/20260928-orca-ade-blog.json。
