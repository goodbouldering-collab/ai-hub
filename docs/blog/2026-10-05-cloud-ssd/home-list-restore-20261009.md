# トップページのブログ一覧を復元（2026-10-09）

依頼対象はトップページの画像付きブログ一覧。PR #108で誤って戻した記事タイトルと画像の縁取りは、PR #107の状態へ復旧する。

- 9月30日の変更で削除された7枚の画像付き一覧を、受講資料と講師紹介の間へ復活。
- 記事は公開中のブログ一覧を基準に新しい順で選ぶ。未公開Markdownを掲載しない。
- ニュース横の最新2件は保持し、そのIDをlatest-blogに変更。メニューの#blogは復元した一覧へ移動する。
- 日次ニュースの生成処理も一覧を再生成・保持し、次回更新で消えないようにする。
- 以前のカード構造・CSS・カルーセル操作を再利用。
- 変更対象はトップ、SSD記事、ブログ索引、sitemap。その他546資産、Worker、本文、既存の未コミット作業は保持。

検証: 一覧欠落時の復旧、再生成の冪等性、公開記事の選別、リンクと画像、記事復旧前とのハッシュ一致、Cloudflareの既存テストを実施。
