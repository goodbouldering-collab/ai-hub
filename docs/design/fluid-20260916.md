# AI相談 — Fluid studio

2026-09-16。AIを学び、仕事で試し、地域の暮らしへつなげる相談サイトのための画像と共通デザイン。

## 制作の方向

本人写真と鋭いコラージュを外し、自然光のなかを滑らかにつながる半透明の素材へ変更した。シリコンバレーの海辺のクリエイティブスタジオを思わせる、霧のセージ・生成り・淡い朝日の色を使う。「人が方向を決め、AIが知識と作業をつなぐ」という、この事業の立ち位置を抽象的な流れとして表現する。

実在する人物・受講風景・施設を描いた写真ではない。構図と素材は本サイト向けの新規アート。技術的機能や実績を画像から主張しない。AIと人の役割を整理する参考として、[Anthropicのエージェント設計記事](https://www.anthropic.com/engineering/building-effective-agents)を確認した。

## 実装

- `core/studio_design.py` が公開HTMLを共通装飾する。トップの本人写真枠・重ねた装飾画像を除去し、トップ講師欄と自己紹介の主画像もflow-connectに置換。
- 本人のJSON-LD `Person.image` だけを除去する。抽象アートを本人写真として登録しない。その他の構造化データを保持。
- `editorial.css?v=20260916-fluid` が角丸、薄い境界、柔らかな陰影を公開・管理・ログインへ適用する。旧版画像や本人写真ファイルは削除しない。
- マウスに反応するヒーローの動きは小さく滑らかにする。タッチや動きを減らす設定では停止する。
- 本文、見出し、ニュース日付、料金、申込先、フォーム、管理・認証処理は保持する。
