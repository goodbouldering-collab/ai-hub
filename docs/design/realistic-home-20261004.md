# 人と仕事が見えるAI相談 — 2026-10-04

対象はAI相談のトップページ。忙しい地域の事業者に、告知作り・学習・業務整理・サイト制作の具体的な用途を写真で伝える。主導線は既存のメニュー選択フロー。伝える一言は「自分の仕事を持ち込んで、一緒に使ってみる」。

ユーザーの修正指定を優先し、抽象オブジェクト案は採用しない。人物と実際の作業を中心に、アート感は自然光・構図・余白・控えめな色使いに留める。温かい白、深い青緑、少量のテラコッタ。見出し、料金、リンク、診断、予約、ニュース、講師本人の画像は保持する。

新規写真は4点。告知を一緒に作る、複数人で学ぶ、PCとスマートフォンで予約ページを確認する、相談しながら週間予定を整理する。built-in image_genで生成し、人物と場面は架空。altとヒーローの注記にAI生成イメージであることを記載する。対面写真をオンラインサロンの説明に流用しない。講師本人・実店舗・実績サイトの既存画像は維持する。

専用CSSはトップページだけに適用。大きな写真と読みやすい文字組みを中心に、半透明の重なったボックスと過剰な装飾を減らす。PCは写真とコピーを横並び、モバイルは写真→コピー。コースはPC3列・タブレット2列・スマホ1列。キーボードフォーカス、メニュー、動きを減らす設定に対応する。
