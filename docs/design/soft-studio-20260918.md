# Soft AI studio — 2026-09-18

## 目的

地域の事業者・学び直す人が、AIで告知、事務、Webサービス制作を進める様子をイメージできる公開サイトにする。既存のサービス説明・料金・申込先を保ち、柔らかく、分かりやすいモダンな表現に刷新する。

細いチャコールの線、柔らかな紙・陶器の立体、生成り・セージ・バター色・少量のアプリコット。人物やアニメキャラクターではなく、ノート・PC・書類・ブラウザなど、身近な道具が成果へつながる場面を描く。文字は実装側に置き、画像に文字情報を依存させない。

## 画像資産

OpenAI built-in ImageGenで13点を個別生成。原本PNGは `soft-studio-originals/`、完全なプロンプトは `soft-studio-20260918-prompts.json`、サイズ一覧は `soft-studio-image-manifest.json`。配信先は `site/static/design-system/studio/images/soft-*.webp`。SharpによるWebP形式変換のみで、画像内容は加工していない。全点1536×1024、合計793,784 bytes。

## デザインと操作

- 半透明の本文パネルを画像に少し重ね、丸み・余白・細い境界線を統一。
- 公開ページ・自己紹介・記事・管理・ログインは共通CSS。
- トップのニュース直下に「AIと、どこから一緒にやろう。」を追加。
- 告知／事務／サイト制作を選び、手作業／AIと進めるを切り替える。材料・任せること・人が確認すること・完成例を表示。
- この体験は架空のサンプルで、入力、外部通信、データ保存は行わない。
- キーボード、タッチ、JS無効時の読み取り、動きを減らす設定に対応。

## 検証・公開

公開中の `4d627efe90c83047289feda87dfaa5ea3cc12416` / Cloudflare `d45f0d92-4a8f-4264-bf57-7bbf3c316264` の保存済みスナップショットを基準にする。

`scripts/build-editorial-release.py` で新規出力先へ生成し、公開HTML186・管理HTML2の既存本文、料金、リンク、フォーム、メタ情報、認証処理を比較。13画像の配置・非重複とdecoratorの冪等性を検査する。

`node --test tests/soft-playground.test.mjs tests/studio-glass-motion.test.mjs` は20件成功。独立レビューで小見出しと暗色CTAのフォーカス枠のコントラストを調整した。

依頼対象だけをコミットし、PRを既定ブランチへ統合。中央台帳の登録ソースへfast-forwardし、同じコミットから再生成してガードを通す。デプロイは `wrangler-profile-release.jsonc` に明示的なentry/assetパスを指定する。PC・iPhone幅の実画面確認はHTTPやコードの確認と分けて記録する。

公開後は `scripts/verify_editorial_live.py` で主要ページ、13画像、CSS/JS、管理/APIの28経路を検証。実行結果、統合SHA、Cloudflare version、ブラウザ結果はリリース出力先の記録およびPRコメントに残す。本ファイルは画面確認やデプロイの完了を先取りして表明するものではない。
