# 温かい線画と小さな差し色 — 2026-09-20

基準画像はユーザーが指定した「Cloudflare・EmDash」の、お店と人物を描いたブログ画像。木・紙・ガラスの質感に、滑らかな細い線とセージ色を組み合わせた。アプリコット色は小さな印と画像の一部分に限定した。

## 変更範囲

- トップ、各コース、学びのステップ、ログインの共通アート11点と、受講資料入口7点を別々の構図で制作。
- 講師画像は最終指示に従い、元の `site/static/img/speaker-anime.png` を無加工で使用。トップと自己紹介のガラス調カード・縁取りでサイトになじませた。
- Instagramは小さな見出し「Instagram」と6枚の画像だけ。画像幅はPC128px、スマートフォン104px。投稿画像・リンクは維持。
- 実績の画面、会場写真、ブログ本文・ブログ画像・ニュース本文は維持。

## 素材

生成方式: built-in imagegen。PNG原本は `warm-line-originals/`、最終プロンプトと参照画像は `warm-line-20260920-prompts.json`。Web用は `site/static/design-system/studio/images/` のWebP（1536×1024、品質88、各約106–176KB）。`warm-line-20260920-contact-sheet.png` で全18点を比較できる。

## 再現と公開

通常ビルドの画像対応は `core/art_direction.py` と `core/studio_design.py` に集約。Instagramは `core/instagram_feed.py` を使用する。

公開中のニュース等を保持するため、検証済みリリースを入力に `scripts/build_warm_line_release.py --baseline <verified-release> --output <new-release>` を実行する。基準SHA・成果物ハッシュは `deployment/editorial/warm-line-baseline.json` に固定。原画像の同一性、本文保持、出力差分、ビルド入力のGit状態を検査する。

コミット・PR・main統合後、中央台帳の登録ディレクトリで再生成し、Cloudflare公開先ガードを通してデプロイする。公開後は `scripts/verify_warm_line_live.py` とアプリ内ブラウザで確認する。最終SHA・PR・Worker版・検証結果は公開元のリリースフォルダに記録する。
