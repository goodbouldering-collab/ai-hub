# AI相談トップページ：講習資料リンクとAIオンラインサロン注釈の調整

**作成日:** 2026-08-07
**対象:** `site/build_portal.py` が生成する公開トップページ (`/index.html`)

## 背景

公開ページ上の4つの注釈を反映する。

1. AIエージェント講習の受講資料への導線を、ボタンではなく通常のテキストリンクとして見せる。
2. 月額・自動更新・LINE参加案内の注記を、Square決済ボタンの直上に置く。
3. 「全部を追わず、新機能と一流の活用事例から、今試すことを短く整理します。」を削除する。
4. サロンの見出し文を「AIの最新も疑問もその場で解決できる。」へ置き換える。

## 採用する方針

### 1. 講習資料リンクを独立した通常リンクにする

`_render_compact_course_cards()` が出力する各講習カードの資料導線を、カード直下の共通ボタン要素から分離する。

- 資料リンクは専用の行要素の中に置き、通常のアンカーテキストとして出力する。
- `compact-course-card > a` の共通ボタン指定を資料リンクに継承させない。
- 資料リンクは青字・下線・内容幅で表示し、ホバー時も通常のリンクとして色だけを変える。
- AIエージェント講習だけでなく、同じ構造を使う講習カードすべてに適用し、カード間の表示を統一する。
- 行の余白はカード内の予約ボタンとの視認上の区切りを保ち、PC・スマホで幅いっぱいの疑似ボタンにならないようにする。

### 2. 決済注記を決済ボタンの直上へ移す

AIオンラインサロンのHTMLを、次のDOM順にする。

1. 詳細（メリット・参加方法）
2. 月額・自動更新・LINE参加案内の注記
3. Square決済ボタン
4. オンラインサロン受講資料へのリンク

DOM順と見た目の順序を一致させ、スクリーンリーダーでも決済条件を読んでからボタンへ進めるようにする。注記は中央揃えを維持し、ボタンの上側に適切な余白を設ける。

### 3. サロン紹介文を簡潔にする

- `salon-intro-summary` の要素と、その不要になったスタイル指定を削除する。
- `salon-intro-tagline` は指定文へ差し替える。
- 料金、開催日時、詳細説明、メリット一覧、LINE参加の決済ゲートは変更しない。

## 変更対象

- `site/build_portal.py`
  - 講習カードの資料リンク用マークアップ
  - 講習カードの資料リンク用スタイル
  - サロン紹介のタグライン・要約文・決済注記・決済フォームの出力順
  - 使われなくなる要約文用スタイル
- `tests/test_course_material_mapping.py`
  - 資料リンクのURL・文言・通常リンク構造を検証する。
- `tests/test_rendered_salon.py`
  - 注記が決済フォームより前に出力されることを検証する。
- `tests/test_salon_content_contract.py`
  - 新しいタグラインの存在と、削除対象の要約文が残らないことを検証する。

## 変更しないもの

- Squareの決済URL、料金、月額課金の仕組み、LINE参加ゲート
- 講習資料のURL・リンク先・予約導線
- サロンのメリット、開催日時、受講資料リンク
- 他ページ、管理画面、既存ブログ、既存の動画・SNS投稿

## 受け入れ条件

### PC・スマホ共通

- AIエージェント講習の受講資料導線が、横幅いっぱいの青いボタンではなく、自然な下線付きテキストリンクとして表示される。
- サロンの注記がSquare決済ボタンの直上に表示される。
- 削除指定の要約文がHTML・画面に存在しない。
- タグラインが `AIの最新も疑問もその場で解決できる。` と完全一致する。
- 予約・決済・受講資料のURLとリンク先が変わらない。

### 検証

1. `site/build_portal.py` と `site/build_site.py` を再生成する。
2. 関連する `unittest` を実行する。
3. 1294px前後のPC幅と390px前後のスマホ幅で、リンクの表示、決済注記の順序、横スクロールの有無を確認する。
4. 変更をコミット・pushし、Vercel本番URLで同じ4点を確認する。

## 実装しない代替案

- CSSの表示順 (`order`) だけで注記を上へ動かす案は採用しない。DOM順が変わらず、読み上げ順と見た目が食い違うため。
- 既存のカード共通ボタンのまま色だけを消す案は採用しない。今後の共通ボタン変更で再発しやすいため。
