# AIとデザインReel・トップ料金表記 改訂設計

## 目的

既存Reelを、デザイナーやクリエイターが一度で意味を理解できる5画面へ整理する。AIを「デザイナーを不要にするもの」ではなく、ロゴ・Webサイト・資料まで仕事を広げる武器として伝える。同時に、トップページの相談料金を固定単価に見えない「5,500円から」へ直す。

## 対象

- Reel生成元: `media/output/myreel/2026-08-06-ai-work-design-future/build_reel.py`
- Reel確認・投稿用成果物: 同ディレクトリの動画、画像、字幕、QA、投稿確認ファイル
- ブログ埋め込み動画: `site/static/video/blog-ai-work-design-future-20260806.mp4`
- トップページ生成元: `site/build_portal.py`
- 生成サイト: `site/dist/`

Instagramへの公開、ストーリーズ共有、コメント投稿はこの実装だけでは行わない。修正版の完成後、投稿セットを再提示して承認を得る。

## 承認済みの5画面

1. `AIでデザイナーは / いらなくなる？`
2. `AIなら / ロゴもサイトも / すぐ作れる`
3. `人が担うのは / お客様の話を聞き / 何を作るか決めること`
4. `デザインを頼む人は / サイトや資料も / まとめて頼みたい`
5. `AIはデザイナーの / 仕事を広げる / 最強の武器になる`

各画面は中央配置、3行以内、9:16、既存のAI相談の配色と余白を維持する。既存の6画面から5画面へ減らし、専門語の「仕事設計」「優先順位」「ワークデザイン」は画面内では使わない。

## ナレーション

表示文と同じ意味を、通常速度の女性ナレーションで読む。3画面目の「人が担う」は、TTS入力だけをひらがなの `ひとがになう` に置き換え、`にんがになう` という誤読を防ぐ。画面表示、字幕、投稿確認文では漢字の「人が担う」を維持する。

生成処理では、表示・記録用のナレーション文とTTS入力を分けられる任意フィールドを設ける。他の画面は従来どおり同じ文から生成する。

## 投稿用成果物

5画面化に合わせ、キャプション、ストーリーズ文、ブランドコメント、投稿マニフェスト、QA、確認HTML・画像を再生成する。新しい主張は足さず、次の流れに統一する。

`AIは作れる → 人がお客様の話を聞いて決める → サイトや資料まで仕事を広げられる`

公開先URLは既存ブログURL、投稿先は `@climbingconsul`、Threadsは対象外とする。

## トップページ料金

トップページのヒーロー内表示を次のように変更する。

- 変更前: `相談5,500円/回`
- 変更後: `5,500円から`

編集対象は `site/build_portal.py` の生成元だけとし、`site/dist/index.html` は通常のサイトビルドで更新する。他の講習・相談料金やFAQは変更しない。

## データの流れ

1. Reelの5画面、表示用ナレーション、TTS読み上げ入力を一つの定義へ置く。
2. 生成スクリプトが音声、フレーム、動画、QA、投稿用文書を再生成する。
3. 完成動画と表紙をブログ用静的ファイルへ同期する。
4. トップ料金文言を生成元で変更し、`site/build_site.py` でサイト全体を再生成する。
5. ローカル検証後にコミット・push・Vercel本番デプロイを行う。
6. 本番のトップページとブログ動画をPC幅・iPhone幅で確認する。

## エラー処理と安全境界

- TTS生成、FFmpeg、音声尺、音量QAのいずれかが失敗した場合は、古い動画を本番へ出さない。
- 5画面すべての表示文とナレーション対応が確認できない場合は、投稿承認へ進まない。
- 本番料金は生成HTMLでも旧文言が消えたことを確認する。
- Instagramのログイン先が `@climbingconsul` でなければ投稿しない。認証情報は取得・保存しない。

## 検証

- Reel単体テスト: 5画面、各3行以内、承認済み文言、3画面目のTTS入力 `ひとがになう`、通常速度、音声QAを確認する。
- サイトテスト: `5,500円から` が生成トップに1件以上あり、`相談5,500円/回` がないことを確認する。
- 全PythonテストとTypeScript検査を実行する。
- `ffprobe`でReelが1080×1920、H.264、AAC、30fps、音声ありであることを確認する。
- ストーリーボードと完成動画を目視し、文字切れ、低コントラスト、誤読、音割れを確認する。
- 本番URL `https://aiclimb.vercel.app/` とブログURLをHTTPとブラウザの両方で確認する。
