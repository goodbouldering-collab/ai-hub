# 無料相談廃止と申込導線の再編

## 目的

無料相談を通常の提供メニューから外し、公開サイトの申込導線を、読者の目的に応じて **AI個別相談** または **AIエージェント講習** へつなぎ直す。例外として、60秒診断を完了した人だけが選べる「無料相談で入口を整理したい」は残す。無料・0円と誤認させる表記、予約先、構造化データは、60秒診断の選択肢と結果以外に残さない。

## 対象範囲

- `site/build_portal.py` の公開ホーム、60秒診断、ヘッダー、モバイルメニュー、フッター、FAQ、コース説明、JSON-LD。
- 公開ブログ `content/blog/2026-07-27-codex-remote-ssh-rdp.md` と生成ページ。
- 上記から生成される `site/dist/` の公開ページ。

過去施策の記録である `content/consul-work/` と、リンクを持たない過去の企画メモは履歴として残す。公開ページや将来再利用されるサイト生成ソースには、無料相談の提供表現を残さない。

## 導線の設計

| 読者の目的 | 表記 | 到達先 |
| --- | --- | --- |
| 課題、優先順位、導入方法を整理したい | AI個別相談（60分・5,500円） | Square の個別相談予約ページ |
| 実際の仕事を一つ進めながら、AIの使い方を身につけたい | AIエージェント講習（120分・5,500円） | AIエージェント講習の申込ページ |
| 60秒診断を終え、まず入口だけ整理したい | 無料相談（診断内限定） | Square の無料相談予約ページ |

共通の判断基準は次のとおりとする。

- 「悩みを聞く」「課題を整理する」「仕組み・導入の進め方を決める」は個別相談へ送る。
- 「投稿文や画像を作る」「実際の仕事を一つ完成させる」「講習で学ぶ」はAIエージェント講習へ送る。
- 60秒診断は `start`、`office`、`flow` を個別相談、`promotion` をAIエージェント講習へ送る。第3問で「無料相談で入口を整理したい」を選んだ場合だけ `free` 結果を返し、無料相談予約へ送る。結果ごとに価格・時間と次の行動を明示する。
- ヒーロー、ヘッダー、モバイルメニュー、フッター、問い合わせ欄の汎用CTAは個別相談へ送る。

予約先は次の2本に固定する。

- 個別相談: `https://book.squareup.com/appointments/zymaszkc9pdwq2/location/LWJNMP7EAN4GS/services/TO3XHZT6XP3OM4QBDYMW7TZP`
- AIエージェント講習: `https://goodbouldering.com/?pid=188553378`
- 診断内限定の無料相談: `https://book.squareup.com/appointments/zymaszkc9pdwq2/location/LWJNMP7EAN4GS/services/AW5O5XSBHLEHYUBHLZUGFKYE`

## 画面とコピー

- 「無料相談」「無料で相談」「初回無料」「0円の入口整理」を、60秒診断の選択肢と `free` 結果以外では、目的に合う有料メニュー名・料金・時間へ置き換える。
- 60秒診断の第3問には「無料相談で入口を整理したい」を残す。選択時は `free` 結果を優先し、「無料相談の日程を選ぶ」を主CTAとして表示する。
- 診断結果の主CTAは上記の目的別リンク、補助CTAは講習・相談コース一覧にする。`free` 結果の補助CTAも講習・相談コース一覧にする。
- 問い合わせ欄は「AI個別相談を予約する」とし、相談で扱う内容と60分・5,500円を明記する。
- ブログ内のPC構成相談へのCTAは「AI個別相談でPC構成を整理する」に変更する。

## データ整合性

- JSON-LDから「AI無料相談 入口整理」と0円の `Offer` を削除する。診断内限定の無料相談は構造化データに掲載しない。
- 「AI個別相談 しっかり60分」の `Offer` に、個別相談の予約URLと5,500円を設定する。
- AIエージェント講習の5,500円・120分・申込URLは維持する。

## 検証

1. 回帰テストで、公開生成物とサイト生成ソースに、60秒診断モーダル以外の無料相談の提供文言・旧予約URL・0円のOfferが残っていないことを検査する。
2. 60秒診断の `start` / `promotion` / `office` / `flow` / `free` 結果が、意図した個別相談、AIエージェント講習、または診断内限定の無料相談URLと対応する文言を出すことを検査する。
3. 既存テスト一式、静的サイト生成、差分の空白チェックを通す。
4. PC幅とiPhone幅で、本番ページのCTA、60秒診断、外部予約リンク、モバイルメニューに横スクロールや誤表記がないことを確認する。

## 非対象

- 過去の社内施策記録の事実を書き換えること。
- Square・カラーミー側のサービス価格や商品設定を変更すること。
- 無料相談以外のコース料金、提供内容、外部予約先を変更すること。
