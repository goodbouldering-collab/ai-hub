# 管理メニュー情報設計

## 目的

管理機能を一列の長いリンク集として見せず、「何をしたいか」で探せる共通メニューへ整理する。公開側のメニューは変更しない。

## 採用案

用途別ドロップダウンを採用する。区切り線だけを足す案は探す負担が残り、左サイドバー案は Blog／Reel 制作画面の作業幅を狭めるため採用しない。

## 情報階層

- 運営: 実行指令室、OPS
- 制作・発信: ブログ管理、ブログ制作、リール制作、SNS投稿
- 分析・相談: SNS分析、AI相談
- 相場: 「調べる」と「計画・記録」に分けて既存8機能を配置
- その他: デザインシステム、公開ページ、ログアウト

「AI相談 管理画面」のロゴは管理ホームへの導線を兼ねる。現在ページを含むグループとリンクの両方を強調する。

## 表示

- PC／タブレット: 固定ヘッダーには5つのグループ名だけを表示し、クリックで説明付きメニューを開く。
- 390px: ハンバーガー内を同じ5グループの折りたたみにする。現在地のグループだけ初期展開する。
- 各項目は「名前」と身近な言葉の説明をセットにする。
- 同時に開くグループは1つ。外側クリック、Esc、リンク選択で閉じる。
- 44px以上の操作領域、フォーカス表示、横はみ出しなしを維持する。

## 実装境界

項目とグループの正本は `site/static/admin/admin-menu.js` の1つのデータ構造に集約する。見た目は `site/static/admin/admin-common.css` の共有ヘッダー境界内だけで定義し、個別ページや公開ページへ漏らさない。

## 成功条件

- 全管理画面で同じグループ、順序、説明が表示される。
- PCで長い横スクロールを使わず、390pxで長大な全展開リストにならない。
- 現在地、キーボード操作、アクセシブルネーム、既存URLを維持する。
