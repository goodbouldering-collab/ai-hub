## 伝えること

**伝えるとは、情報を渡すことではない。相手の次の一歩を軽くすることだ。**

5場面で、`100を理解する → 10を見せる → 1を持ち帰ってもらう` を示します。テロップと女性ナレーションは、句読点・改行以外を同じ言葉にそろえています。

## 表現方針

- 落ち着いた実務的なトーン。誇張、流行語頼み、冒頭のジョークは使わない。
- 記事の図解をそのまま使い、サイト・リール・ブログ一覧で主張を一致させる。
- BGMはこのキャンペーン用にコードで生成したソフトパッド。ナレーション中は自動で音量を下げる。
- 最後の行は記事URLにする。投稿後は `post-record.json` に実際のリールURL・ストーリー・コメントの結果を記録する。
