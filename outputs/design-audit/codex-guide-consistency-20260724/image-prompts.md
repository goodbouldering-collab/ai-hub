# Codex Worktree記事 画像生成プロンプト

生成方法: Codex組み込みの画像生成

## 共通アートディレクション

- 用途: AI相談ブログの科学・教育向け図解
- 比率: 3:2の横長
- 画風: やさしく上質な3D教材イラスト
- 背景: 白〜ごく薄い青
- 配色: ネイビー、青、青緑を中心に、少量のオレンジと紫
- 質感: 柔らかい影、角の丸い形、清潔感
- 制約: 文字、英字、数字、コード、ロゴ、商標、透かしを入れない

## 1. 表紙

CodexのWorktree、Git、Pull Request、デプロイまでの流れを、町のパン屋さんのたとえで一目で理解できる教材イラスト。いつものパン屋の厨房と、分離された試作厨房、レシピを記録するノート、確認用カウンター、公開中の店頭へ届ける配送の流れを、左から右へ自然につなぐ。中央に主役を置き、上下左右に十分な余白を取る。小さなスマホ画面でも主要要素が分かるようにする。

## 2. 第1章 — 作業場所と安全範囲

Local、Worktree、Sandbox、Branchの違いを、同じパン屋の世界で直感的に表す。ひとつの通常厨房、壁で分かれた独立試作厨房、その周囲を守る透明な安全枠、2つの厨房から伸びる色違いのレシピカード束を描く。左右比較が分かる構図にし、安全枠とレシピ束は補助要素にする。

## 3. 第2章 — LocalかWorktreeかを選ぶ

中央の店主が、小さな修正をする通常厨房と、大きな新メニューを試す独立試作厨房のどちらへ進むか見比べる。手元にはチェック項目のカード、奥にはローカル確認・確認用展示・営業中の店頭を示す3つの段階的な小さな模型を並べる。選択と公開段階の違いが小画面でも分かるようにする。

## 4. 第3章 — Gitの基本工程

CodexとGitの基本操作を、整理されたパン作りの記録工程として表す。パソコン上の作業フォルダー、変更を選ぶトレー、履歴を残すリングノート、雲へ送る小型コンベア、レビューする確認カウンターを左から右へつなぐ。一人が作業し、もう一人が最後に確認する。

## 5. 第4章 — 人の確認と本番公開

地域の小さな事業者と講師がレビュー用の資料を一緒に見て確認し、その先でパソコンとスマートフォンに同じパン屋サイトが正しく表示され、営業中の店頭に大きな緑の確認印が付いている。左に人同士の確認、中央にPCとスマホ、右に公開中の店頭を置き、完了の流れを表す。
