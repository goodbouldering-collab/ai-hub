# Codex使用量ブログ 最終レビューパック

## 目的

- 誰に: ChatGPTとCodexの使い分けや使用量が気になる地域事業者、講座受講者、AI初心者
- 悩み: どの画面・モデルを選べばよいか分からず、使用量をムダにしたくない
- 読後の行動: Chatで方針を決め、CodexはLunaまたはTerraから始め、Usageで実績を確認する
- 発信先: AI相談ブログ

## 検討した仮タイトル

1. Chat・Work・Codexはどう使い分ける？AIの使用量をムダにしない一番簡単な方法
2. Codexの使用量が気になる人へ｜重い作業を分けてムダを減らす方法
3. 迷ったらこれだけ｜相談はChat、実行はCodex、完成資料はWork

選択: 1。検索時の疑問をそのまま表し、Chat・Work・Codexの3つを漏れなく扱えるため。

## 検討したH2グループ

### A: 問題から解決へ

1. Chatは相談、WorkとCodexは実作業に使う
2. モデルはLunaから始め、必要な時だけTerra・Solへ上げる
3. 長い出力と長い会話を減らすと使用量を抑えられる
4. 迷ったら「Chatで整理、Codexで実行、Usageで確認」

### B: 失敗と修正

1. すべてをCodexで相談すると実作業の前に使用量が増える
2. 最初からSolを選ばず作業の難しさでモデルを変える
3. 長いスレッドと報告を短くすると確認も軽くなる
4. Usageの実績を見て自分の使い方を調整する

### C: 比較と選び方

1. Chat・Work・Codexの違いは作る成果物で決まる
2. Luna・Terra・Solは作業の重さで選ぶ
3. 使用量を減らす4つの具体策
4. 1日の使い分けを4段階で決める

選択: A。初心者が「今どれを選ぶか」をそのまま判断でき、各H2が節の結論になっているため。

## 事実確認

- OpenAI公式の2026年7月31日時点の説明で、Chat・Work・Codexの用途を確認。
- WorkとCodexが同じエージェント使用構造であることを確認。
- Codexのクレジットが入力・キャッシュ済み入力・出力のトークン種別で計算されることを確認。
- Luna・Terra・Solの単価順と、出力が入力より高いことを確認。
- Ultraの追加エージェントとFastモードの消費増加に関する注意を確認。
- 元資料の倍率・単価は現在の英語版公式レート表と一致しないため、本文には固定倍率を掲載しない。
