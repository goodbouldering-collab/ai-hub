AI相談 ブログ管理

ブログ作業を、機能ごとのページで切り替えます。

必要な機能だけを開けるため、長い管理画面をスクロールせずに作業できます。

記事作成だけを、迷わず前へ進める 設定、一覧、生成、編集、公開を独立したページに分け、必要な作業だけに集中できます。
00全体 01接続 02設定 03記事一覧 04AI生成 05編集・画像 06公開

ブログ管理の機能別ページ

01 / CHECK接続状態

カラーミー、AI、画像保存先の設定状況を確認します。

接続ページを開く → 02 / SETUPブログ設定

ブログ親グループIDをこのブラウザに保存します。

設定ページを開く → 03 / ARTICLES記事一覧

既存記事の編集と表示順の変更を行います。

記事一覧を開く → 04 / GENERATEAI記事生成

テーマから複数の下書きを作り、採用案を選びます。

AI生成を開く → 05 / EDIT編集・画像

本文を整え、AI修正と画像生成を行います。

編集ページを開く → 06 / PUBLISH公開

最終内容を確認し、グループ更新と公開を実行します。
