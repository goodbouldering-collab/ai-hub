ブログ・リール作成

ブログとリールは別ファイル・別画面です。事業プロフィールを選択済みの専用App Serverを開きます。

ブログ App Server

  • SEO・MEO・LLMOとトレンド調査
  • タイトル3案・H2構成3案
  • 一次情報を使った本文とH2直下画像
  • 最終タイトル再評価と実表示プレビュー
ブログ専用画面へ

リール App Server

  • リール企画3案
  • 承認済み素材4〜5件
  • 9:16の5場面プレビュー
  • Chromeのログイン済みアカウントで投稿準備
リール専用画面へ
OpenAI APIキーは各専用画面でセッション中だけ入力できます。リールの最終シェアは、判断.mdの投稿先確認と、この内容への明示承認後にChromeで行います。
